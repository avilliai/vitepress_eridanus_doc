# WebUI 初次使用与上手指南

第一次打开控制台有点摸不着头脑？跟着我的步骤走就好啦，两分钟就能玩转~

## 第一步：确认服务开启与监听端口

打开你的 `run/common_config/basic_config.yaml`，确认以下字段：

```yaml
webui:
  enable: true      # 确保设为 true，否则 WebUI 不会启动
  auth_token: "" # 这个是给app配套用的，我们暂时用不到
```

启动 Eridanus 主程序，留意控制台终端输出：
你会看到类似 `WebUI running on http://127.0.0.1:5007` 的启动日志，这就说明网页服务已经在乖乖待命啦。

## 第二步：浏览器访问与认证

1. 在浏览器地址栏输入：`http://127.0.0.1:5007`（如果是远程云服务器，请把 `127.0.0.1` 替换为服务器的公网 IP，并确保安全组放行了 `5007` 端口）。
2. 默认账户密码都是`Eridanus`


## 第三步：在网页上修改配置

进入 **“配置编辑 (Config Editor)”** 页面：
1. 在左侧文件树中找到你想调整的插件，比如 `run/basic_plugin/config.yaml`。
2. 在右侧编辑器中直接修改键值（比如把某个开关改成 `true` 或填入 API Key）。
3. 点击 **保存** 按钮，修改内容就会直接写入服务器磁盘。
4. 如果修改的是全局连接、Master ID 或者端口类字段，别忘了在控制台把主程序重启一下让底层重新连接哦。
