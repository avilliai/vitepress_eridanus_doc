# WebUI 初次使用指南

准备好进入属于我们的控制台了吗？跟着 Yucca 这三步走，保姆级引导带你快速登入！    

---

## 第一步：确认服务启动

当你运行 `python main.py`（或者双击 Windows 整合包的启动脚本）后，终端输出中看到类似以下日志：    

```text
[SERVER] WebUI 运行于 http://0.0.0.0:5007
[SERVER] WebSocket 服务端已就绪，等待客户端连接...
```

这就代表 WebUI 和反向 WebSocket 枢纽已经成功跑起来啦！    

---

## 第二步：浏览器访问与登录

1. 打开浏览器（Chrome / Edge / Safari 等均可），输入地址：    
   `http://127.0.0.1:5007`    
2. 如果你在 `basic_config.yaml` 中留空了 `auth_token`，将直接进入控制面板；    
3. 如果配置了密码，输入对应的 Token 即可完成鉴权。    

---

## 第三步：快速测试与聊天

进入左侧菜单的 **网页模拟对话**（Chat Sandbox）：    
- 你可以模拟管理员或者普通群员发送消息；    
- 试试发送 `hi` 或者调用各种指令；    
- 如果你配置了 MaiReply 对话核心，就能在这个界面直接看到我的回复与工具调用记录啦！
