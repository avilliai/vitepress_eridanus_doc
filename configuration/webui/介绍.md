# WebUI 控制台

总是在黑漆漆的命令行终端里改 YAML，是不是偶尔也会觉得眼睛酸酸的？别担心，Eridanus 自带了一套图形化的 WebUI 仪表盘控制台哦！

服务由 `web/` 模块驱动，主程序启动时即可在后台拉起这个贴心的网页小管家，让你随时随地用鼠标轻松打理整个机器人。

## 源码入口与核心配置

- **代码入口**：`web`


## 核心功能面板一览

- 📊 **系统状态总览**：实时掌握 CPU 占用率、内存开销、已连接的适配器状态与活跃群聊数量。
- ⚙️ **可视化配置编辑**：把让人头大的各模块 `config.yaml` 转变成清爽的表单输入框，改完一键保存生效！
- 👥 **用户与权限管理**：免敲命令直观查看用户列表、修改权限数值、给指定群友开通白名单。
- 📜 **实时日志流**：浏览器端直接滚动查看控制台日志，调试 Bug 一清二楚。

## 如果你想做什么，应该改哪里？

1. **想换一个端口访问 WebUI（例如 8080 被占用）**：
   - 打开 `run/common_config/basic_config.yaml`；
   - 将 `web_ui.port` 修改为你期望的空闲端口（如 `9090` 或 `5200`）。
2. **只想本机访问，禁止外网登录**：
   - 将 `web_ui.host` 从 `0.0.0.0` 改为 `127.0.0.1`。
3. **忘记了 WebUI 登录密码**：
   - 运行项目根目录下的密码重置工具或查看首次启动日志输出的初始凭证。
