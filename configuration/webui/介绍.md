# WebUI 控制台介绍

谁说管机器人只能在黑漆漆的终端里敲命令的？    
Eridanus 内置了颜值与实力并存的现代 WebUI 控制台，只要启动主程序，在浏览器打开 `http://127.0.0.1:5007` 就能直接上手！    

---

## 核心功能概览

在 WebUI 里，你可以做到以下这些事情：    

1. **实时仪表盘**：查看当前 CPU/内存占用、运行时间、插件加载总数以及接收/发送消息统计。    
2. **可视化配置中心**：所有 `run/*/` 下的 YAML 配置文件都在这里分门别类排好，再也不怕 YAML 缩进错位或者打错冒号啦！    
3. **插件开关矩阵**：一键启用、禁用或热重载某个功能模块，哪里不爽点哪里。    
4. **日志实时流**：直连控制台日志流，报错提示一目了然。    
5. **网页模拟聊天室**：直接在 Web 界面以虚拟用户身份跟我（或者经典 AI）对话调试，无需在 QQ 里频繁刷屏。    

---

## 安全与端口说明

- **默认监听端口**：`5007`。    
- **安全验证**：强烈建议在服务器公网部署时，在 `run/common_config/basic_config.yaml` 中设置 `webui.auth_token`，避免控制台被坏人乱按哦！
