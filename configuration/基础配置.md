# 基础配置中心

呐，想要让我顺利跑起来，第一步当然得先带我认认家门啦~ 这里的每一个参数就像是我的中枢神经，稍微填错一点我可能就会迷路或者罢工哦。

项目的全局中枢配置文件就在 `run/common_config/basic_config.yaml`，不管是我的名字、主人是谁、还是怎么连上 QQ 协议端，都在这里整整齐齐地躺着呢。

## 核心配置片段一览

```yaml
# 机器人与主人基础身份
bot: "Eridanus"   # 机器人的名字，平时大家怎么叫我
master:
  name: "管理员"   # 主人的称呼
  id: 1840094972   # 主人的 QQ 号！最高权限依据，千万别填错哦

group: 879886836   # 测试群号，我会往这里发一些自检和调试的碎碎念，可别填成日常热闹的大群啦

# 协议适配器连接（机器人作为 WebSocket 客户端）
adapter:
  name: "any"      # 协议端兼容选项，如果用 Lagrange 请填写 "Lagrange"，其他 OneBot 协议端保持 "any" 即可
  ws_client:
    ws_link: "ws://127.0.0.1:3001"  # ws server地址

# WebUI 控制面板
webui:
  enable: true     # 是否开启 WebUI 控制台
  auth_token: ""   # WebUI 访问令牌（强烈建议公网部署时填上复杂密钥）

# 网络代理设置（网络不畅通或者调用外网接口时必备）
proxy:
  http_proxy: ""   # 例如: "http://127.0.0.1:7890"
  socks_proxy: ""  # 例如: "socks5://127.0.0.1:7890"

# 插件加载策略与性能调优
PluginLoadConfig:
  load_strategy: "batch_loading" # 加载策略：batch_loading（分批加载）、all_at_once、memory_aware
  batch_size: 4                  # 每批加载的插件数量
  batch_delay: 2                 # 批次之间的缓冲时间（秒）
  memory_threshold_mb: 200       # 内存预警阈值
  enable_gc_between_batches: true# 批次间是否强制回收内存

# 其它核心服务支持
redis:
  redis_ip: default              # 默认本机，Docker 部署请填网桥 IP
  redis_port: default
  redis_db: default

git_update_source: 0             # 远程更新源：0 为 GitHub 官方源，1 为 GitCode 国内镜像
```

## 如果你想做什么，应该改哪里？

（眨了眨眼，指尖戳戳屏幕上的配置项）看好下面这些常见场景哦，别到时候到处找不着对应的开关~

- **你想认领我，当我的主人？**
  - 改 `master.id`！把后面的数字换成你自己的 QQ 号。我是以这个 QQ 号判断 Master 绝对控制权限的，谁填了这里，谁就能直接指挥我、使用最高权限指令。
- **改改我的名字？**
  - 改 `bot` 字段。比如改成 `"Yucca"` 或者其他你喜欢的名字，很多提示语和名片都会跟着一起变哦。
- **协议端连不上、控制台一直在重试？**
  - 重点检查 `adapter.ws_client.ws_link`！确认协议端（比如 LLOneBot、Lagrange、NapCat 等）监听的 WebSocket 端口和地址是不是跟这里完全一致。如果你用的是 Lagrange，记得把 `adapter.name` 改成 `"Lagrange"` 提高兼容性。
- **AI 画图、外网搜索或者翻译总报网络超时？**
  - 快看 `proxy` 这一组配置！把 `http_proxy` 或 `socks_proxy` 填上你的本地代理地址（比如 `"http://127.0.0.1:7890"`）。不填的话，很多境外 API 可是完全敲不开门的。
- **机器配置不高，启动时瞬间卡死或爆内存？**
  - 调一下 `PluginLoadConfig`：把 `load_strategy` 保持为 `"batch_loading"`，把 `batch_size` 调小（比如设为 `2`），`batch_delay` 稍微加长（比如 `3` 秒），我就会慢慢地、一个接一个温和地加载插件啦。
- **在国内服务器上 `git pull` 慢如蜗牛甚至失败？**
  - 把 `git_update_source` 改成 `1`，系统就会自动切换走 GitCode 镜像源啦。

::: tip 小提醒
改完基础配置（特别是协议端连接、适配器、端口或者代理），一定要老老实实**重启主程序**才会生效哦。这些底层网络连接可不支持半路偷换~
:::
