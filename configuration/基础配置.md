# 基础配置指南

欢迎来到 Eridanus 的核心中枢！这里是整个机器人能够顺利启动、认证与对话的基础配置中心~    
要想让我能够顺畅地在群里撒欢、陪你聊天，第一步当然是把基础配置文件调教好啦。    
基础配置文件的相对路径是：    
`run/common_config/basic_config.yaml`    

---

## 认识你的第一个配置文件

你可以使用最顺手的文本编辑器打开它，或者直接在我们的 WebUI（默认端口 5007）里修改。    
下面我把最关键的配置项拆解给你看，可别填错咯：    

```yaml
# 机器人与管理员基础信息
bot: "Eridanus"   # 机器人的昵称，群友叫我或者 @我的称呼
master:
  name: "管理员"  # 机器人对主人的尊称
  id: 1840094972   # 管理员的 QQ 账号！用于启动推送、私聊报警与授权
group: 879886836   # 默认测试群号（开发测试用）

# 协议适配与连接模式
adapter:
  name: "any"     # 适配器类型：如果是 Lagrange 则填 Lagrange，其他 OneBot 实现保持 any
  ws_client:
    ws_link: "ws://127.0.0.1:3001"  # 作为 WebSocket 客户端时连接协议端的地址

# 权限与黑白名单机制
user_handle_logic: blacklist  # 用户名单模式：blacklist（黑名单模式）或 whitelist（白名单模式）
user_handle_logic_operate_level: 1000 # 拉黑/解黑用户所需的操作权限等级
group_handle_logic: blacklist # 群名单模式：blacklist 或 whitelist
group_handle_logic_operate_level: 1000 # 拉黑/解黑群所需的操作权限等级
邀请bot加群所需权限: 0
申请bot好友所需权限: 0

# 进阶功能开关
webui:
  enable: true        # 是否开启内置 WebUI（集成了 5007 端口的控制台与反向 WS 服务端）
  auth_token: ""      # 访问 WebUI 或连接反向 WebSocket 的密钥，留空则免密
record_mface: true    # 是否自动收集主人的表情包缓存
proxy:
  http_proxy: ""      # 全局 HTTP 代理（访问外部 AI/API 必备）
  socks_proxy: ""     # 全局 SOCKS 代理
```

## 协议端连接首选：SnowLuma

再次敲黑板提醒！现在最推荐的 OneBot v11 协议端是 **[SnowLuma](https://snowluma.github.io/zh/)**！    
由于 Eridanus 启动时会自动在 `5007` 端口开启 WebUI ，且Eridanus默认是 WebSocket client，因此你需要：    
1. 打开 SnowLuma 的配置；    
2. 新增一个 WebSocket（WebSocket server）服务端，端口填：`3001`，token留空；
3启动 SnowLuma 登录你的 QQ，就能直接看到终端显示握手成功啦！

## 常用热修改与生效机制

- **即时生效**：大部分业务插件配置和词库修改保存后会自动热重载。    
- **需要重启**：修改了 `basic_config.yaml` 中的监听端口、适配器类型或主 QQ 号，需要重启一次主程序才能生效哦。
