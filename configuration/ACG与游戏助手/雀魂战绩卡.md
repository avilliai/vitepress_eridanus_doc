# 雀魂战绩卡与段位追踪

猫粮少女怎么能不会打麻将呢？    
Eridanus 接入了雀魂麻将第三方开放接口（位于    
run/acg_infromation/majsoul.py），支持一键生成精致绝伦的段位图表与四麻/三麻对局分析卡片！    

---

## 核心亮点

- **自动排版战绩画板**：直观展示一位率、连对率、放铳率、立直率与被炸庄记录。    
- **多维度支持**：支持四人麻将（金之间、玉之间、王座之间）与三人麻将全场次。    
- **多轮次查询**：绑定后只需发送简短指令即可直达战报，也支持随时查询任意路人高手。    

---

## 真实触发指令全集

以下指令完全对应    
run/acg_infromation/majsoul.py 的实际触发代码：    

### 1. 账号绑定与注册
- **注册/绑定游戏昵称**：    
  - 雀魂注册 `<雀魂游戏昵称>`    
  - 示例：雀魂注册 赖大少爷    
  - 绑定后，后续查询自己的战绩无需再次输入昵称。    

### 2. 个人综合信息查询
- **查询已绑定玩家**：    
  - 雀魂信息、雀魂查询 或 雀魂账号    
- **查询指定玩家**：    
  - 雀魂信息 `<游戏昵称>`、雀魂查询 `<游戏昵称>` 或 雀魂账号 `<游戏昵称>`    
  - 示例：雀魂查询 魔女的夜宴    

### 3. 四麻对局与段位卡片
- **四麻段位与基础信息**：    
  - 雀魂四麻查询 或 雀魂四麻信息（可后接 `<昵称>`）    
- **四麻历史战绩与对局走势**：    
  - 雀魂四麻记录、雀魂四麻战绩、雀魂四麻历史记录 或 雀魂四麻历史（可后接 `<昵称>`）    

### 4. 三麻对局与段位卡片
- **三麻段位与基础信息**：    
  - 雀魂三麻查询 或 雀魂三麻信息（可后接 `<昵称>`）    
- **三麻历史战绩与对局走势**：    
  - 雀魂三麻记录、雀魂三麻战绩、雀魂三麻历史记录 或 雀魂三麻历史（可后接 `<昵称>`）    

### 5. 通用对局战绩
- **快速拉取最近对局卡片**：    
  - 雀魂战绩、雀魂记录、雀魂历史记录 或 雀魂历史（可后接 `<昵称>`）
