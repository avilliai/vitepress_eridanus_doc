# 雀魂战绩查询与牌谱卡

（优雅地抓起一张红宝五万，轻轻扣在牌桌上）立直！一发！自摸！谁才是群里的真正雀圣呢？

本功能直接连接雀魂牌谱公开数据库，为雀士们生成逼格满满的战绩卡，四麻三麻排位分、一位率、放铳率一目了然！

## 源码入口与核心配置

- **代码入口**：`run/acg_infromation/majsoul.py`
- **后台服务**：`service/majsoul/majsoul_plugin.py`
- **配置文件路径**：`run/acg_infromation/config.yaml`

配置片段如下：

```yaml
绘图框架:
  gal_recommend: true   # galgame 推荐是否接入绘图框架
  majsoul_search: true  # 雀魂搜索功能是否接入绘图框架生成高清战绩卡（设为 false 则为纯文本输出）
```

## 触发指令

所有指令以 `雀魂` 开头：

| 指令格式 | 示例 | 作用说明 |
| :--- | :--- | :--- |
| `雀魂注册 <昵称>` | `雀魂注册 喵喵雀圣` | 将当前 QQ 与你的雀魂游戏角色昵称进行绑定 |
| `雀魂查询` / `雀魂战绩` / `雀魂信息` | `雀魂查询` | 直接查询自己已绑定的四麻综合战绩与段位点数 |
| `雀魂查询 <目标玩家昵称>` | `雀魂查询 咲-Saki-` | 查询指定牌友的战绩数据与对局历史 |
| `雀魂三麻战绩` / `雀魂三麻查询` | `雀魂三麻战绩` | 专项生成三人麻将的段位与得点卡片 |
| `雀魂四麻战绩` / `雀魂四麻查询` | `雀魂四麻战绩` | 专项生成四人麻将的段位与得点卡片 |

## 如果你想做什么，应该改哪里？

1. **服务器性能弱，卡片渲染太慢或想节省流量**：
   - 打开 `run/acg_infromation/config.yaml`；
   - 将 `绘图框架.majsoul_search` 改为 `false`；
   - 此时战绩数据将直接以结构化文本列表快速发送，轻巧又省心！
