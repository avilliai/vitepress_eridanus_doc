# Epic喜加一周免

由 `run/anime_game_service/epicfree.py` 驱动，掌握 Epic Games Store 每周限时免费送出的精品游戏资讯，白嫖永不落空！    

---

## 核心特性

- **本周免费游戏速览**：自动抓取当前正处于免费领取周期的游戏标题、原价与截止时间。    
- **下周预告同步**：提前获知下周即将开启领取的游戏名单。    

---

## 真实指令列表

- **查询本周限免**：    
  - 发送 `epicfree` 或 `epic喜加一`    
  - 返回图文并茂的免费领取名单与直达链接。    
- **获取帮助**：    
  - 发送 `epichelp` 或 `epic帮助`
