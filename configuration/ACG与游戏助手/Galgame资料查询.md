# Galgame 资料库与智能推荐    

连接专业 Galgame 数据库与开放 API，不仅能全面检索视觉小说、厂商社团、角色声优与发售档案，还提供日常随机安利与新作速报！    

---

## 核心功能    

- **精准与模糊双模检索**：支持按游戏全名、别名、关键字或游戏 ID (gid) 检索。    
- **社团与角色档案**：输入制作厂商/组织或角色名称，快速调取资料与关联作品。    
- **新作与排期速递**：实时获取今日、昨日或本月最新发售的视觉小说新作情报。    
- **日常随机推荐**：选择困难症福音，支持随机抽选高质量神作与推荐理由。    

---

## 常用指令与使用示例    

群聊中直接发送以下指令即可：    

### 1. 游戏查询与检索    
- **模糊搜索**：`gal查询 [游戏名]` 或 `gal搜索 [游戏名]`（例：`gal查询 苍之彼方的四重奏`）    
- **精确查找**：`gal精确查询 [游戏名]`（例：`gal精确查询 WHITE ALBUM2`）    
- **组织/社团作品查询**：`gal查询 机构:[机构名]` 或 `gal查询 机构游戏:[机构名]`（例：`gal查询 机构:Key`）    
- **角色档案查询**：`gal查询 角色:[角色名]`    

### 2. 随机构想与安利    
- **随机推荐**：发送 `gal推荐`、`galgame推荐` 或 `随机gal`，为你随机送上一款精选游戏详情与简介。    

### 3. 新作动态速查    
- **今日新作**：`今日新作` / `本日新作`    
- **昨日新作**：`昨日新作`    
- **当月新作**：`本月新作` / `当前新作`

## 配置文件说明    

在 `run/acg_infromation/config.yaml` 中可调整渲染输出方式：    

```yaml
绘图框架:
  gal_recommend: true   # Galgame 推荐结果是否接入绘图框架渲染图片，若为 false 则以合并转发聊天记录形式发送
```
