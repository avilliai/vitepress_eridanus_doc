# Galgame 资料库与推荐

（悄悄凑近屏幕，压低声音）嘿嘿，群里有没有美少女游戏同好？不管是柚子厨、Key 社厨还是各种纯爱废萌党，这里都是属于我们的秘密基地~

该模块对接了专业 Galgame 数据库 YMGalgame API，不仅能查作品发售日、制作会社和登场女主角，还能每天抽取今日运势 Gal 推荐呢。

核心代码位于：`run/acg_infromation/galgame.py`  
配置文件位于：`run/acg_infromation/config.yaml`

## 源码里真正支持的交互指令

指令匹配包含特定关键词触发，格式灵动随性：

### 1. 每日与每月游戏推荐
消息中只要同时包含 `gal`（大小写皆可）以及时间词（`今日/今天/本日/昨日/本月`）：
- 示例：`今日gal推荐`、`今天gal推荐`、`本月gal推荐`
- 效果：从浩瀚的游戏库中随机挑选优质作品，生成带封面图与剧情简介的安利卡片。

### 2. 作品与机构精准查询
消息包含 `gal` 且包含 `查询` 时触发以下细分分支：
- **查游戏**：包含“游戏”或“id”
  - 示例：`gal查询游戏 千恋万花`
  - 示例：`gal查询 id 12345`
- **查制作会社 / 机构**：包含“机构”
  - 示例：`gal查询机构 Yuzu-Soft`
  - 示例：`gal查询机构 Key`
- **查角色**：包含“角色”
  - 示例：`gal查询角色 常陆茉子`

## 核心配置片段一览（`run/acg_infromation/config.yaml`）

```yaml
绘图框架:
  gal_recommend: true   # Galgame 推荐是否接入绘图框架渲染图片（若为 false 则以合并转发聊天记录发送）
```

## 如果你想修改，应该改哪里？

- **服务器生图速度慢，想要更轻量文字流？**
  - 把 `绘图框架.gal_recommend` 改为 `false`，推荐结果就会以聊天记录转发形式极速发送，省流量又省性能。
