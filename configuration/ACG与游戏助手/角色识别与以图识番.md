# 二次元角色识别与以图识番

（歪了歪小脑袋，端详着屏幕上的照片）“在群里看到一张超可爱的二次元老婆，却死活想不起她叫什么名字、出自哪部动漫？”

别急着到处发帖“求求了，好人一生平安求出处”啦！直接把图丢给我，我来帮你辨认这位二次元角色和她的出处动画！

## 源码入口与核心配置

- **代码入口**：`run/acg_infromation/character_identify.py`
- **识别引擎**：`run/basic_plugin/service/imgae_search/anime_trace.py`（基于 AnimeTrace 特征网络深度学习模型）
- **通用搜图配置**：`run/basic_plugin/config.yaml`（`image_search.sauceno_api_key`）

```yaml
image_search:
  sauceno_api_key: "" # 可选填 SauceNAO 搜图 API Key 作为辅助图源
```

## 源码里真正支持的触发指令

指令由 `character_identify.py` 精确捕获：

| 触发方式 | 操作步骤                                         | 输出效果 |
| :--- |:---------------------------------------------| :--- |
| **图文同行** | 发送一条包含 `识别` 文本 + 图片的消息                       | 定位角色面部与服饰，输出角色名、原作动画名与匹配置信度（百分比） |
| **交互等待** | 1. 发送文字 `识别`<br>2. Bot 回复进入待命<br>3. 接着发送目标图片 | 效果同上 |

> **注意特化范围**：本引擎针对二次元动漫插画、截图与同人绘图进行了专门训练，三次元真人自拍或者现实风景照片可识别不出来的哦~

## 如果你想做什么，应该改哪里？

1. **还想进一步搜高清原图与画师 Pixiv ID**：
   - 可在 `run/basic_plugin/config.yaml` 填写 `image_search.sauceno_api_key`，通过通用搜图模块直接反查 Pixiv 原画师。
