# 米游社与绝区零助手

米家全家桶玩家的福音！由 `run/anime_game_service/mihuyo_club.py` 与 `ZZZ.py` 强力驱动，轻松搞定每日签到、实时便签与绝区零绳匠档案！    

---

## 核心支持游戏

- 原神（Genshin Impact）    
- 崩坏：星穹铁道（Honkai: Star Rail）    
- 绝区零（Zenless Zone Zero）    
- 崩坏3（Honkai Impact 3rd）    

---

## 真实指令一览

### 1. 米游社基础功能
- **绑定账号**：    
  - `米游社绑定`、`米游社登录`、`绑定米游社` 或 `mihuyobind`    
- **日常签到**：    
  - `米游社签到` 或 `mihuyosign`：完成绑定游戏的角色福利签到    
  - `米游币签到` 或 `mihuyocoinsign`：自动完成社区米游币任务    
  - 快捷签到：`原神签到`、`星铁签到`、`绝区零签到`    
- **实时便签**：    
  - `原神便签`、`星铁便签`、`绝区零便签`（查看体力/树脂溢出情况）    
- **切换当前游戏**：    
  - `mysgamechange <游戏简写>`    
- **查看帮助**：    
  - `米游社帮助` 或 `mihuyohelp`    

### 2. 绝区零专属指令
- **绝区零绑定**：    
  - `zzz绑定` 或 `zzzbind`
