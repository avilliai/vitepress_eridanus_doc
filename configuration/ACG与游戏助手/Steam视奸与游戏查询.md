# Steam 视奸监控与游戏信息查询    

群友又在偷偷通宵打游戏不睡觉？或者背着你偷偷开黑？    
开启 **Steam 视奸与活动跟踪系统**（位于 `run/anime_game_service/SteamSnooping.py` 与 `run/acg_infromation/steam_service.py`），全天候抓包群友的摸鱼实况！    

---

## 核心亮点    

- **实时活动监控与播报**：后台定时轮询已监听好友的在玩状态，一旦有人启动或退出游戏，自动在群内播报！    
- **好友状态看板**：实时生成精美好友状态画板，谁在线、谁离线、谁在挂机一目了然。    
- **游戏信息与史低检索**：快速检索 Steam 游戏价格、好评率、详细简介与封面。    
- **AI 对话 Function Calling 深度联动**：聊天中无需前缀指令，随口一问即可让 AI 调取游戏档案。

## 真实指令全集与触发前缀    

以下指令严格对齐底层真实代码实现，支持多种触发前缀与别名：    

### 1. 账号绑定与个人信息    
- **绑定 Steam 账号**：    
  - 指令：`steambind [Steam好友代码或SteamID]`    
  - 示例：`steambind 123456789`    
  - 效果：将群名片/QQ 号与 Steam 档案绑定。    
- **查看个人 Steam 详情**：    
  - 指令：`steaminfo` 或 `steaminfo [SteamID]`    
  - 效果：输出个人近期游玩、等级与在线状态卡片。    

### 2. 状态监听与视奸管理    
- **将好友加入视奸列表**：    
  - 指令：`steamadd [@群友 或 SteamID]`    
- **移出视奸列表**：    
  - 指令：`steamremove [@群友 或 SteamID]`    
- **一键添加/移除全员**：    
  - 指令：`steamaddall`（一键监听群内所有已绑定成员）    
  - 指令：`steamremoveall`（一键清空群监听列表）    
- **即时检查当前状态看板**：    
  - 指令：`steamcheck`    
  - 效果：立即生成群内视奸成员当前的在线与正在运行游戏画板。    
- **获取帮助**：    
  - 指令：`steamhelp` 或 `steam帮助`    

### 3. 游戏本体资料查询    
- **指令格式**：`steam查询 [游戏名称]`    
- **示例**：`steam查询 怪物猎人荒野`    
- **效果**：返回包含游戏 AppID、中文译名、Steam 商店直链、官方介绍与游戏大图。
