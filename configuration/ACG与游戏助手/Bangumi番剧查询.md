# Bangumi 番剧与 ACG 检索

聊到二次元补番和看番，Bangumi（bgm.tv）可是咱们的老家呀~ 

无论是查新番、查老番、看每日放送表，还是找动漫的原声音乐和游戏资料，我都能连线 Bangumi 为你排版生成漂亮的图文卡片哦！

核心代码位于：`run/acg_infromation/bangumi.py`  
服务驱动位于：`service/bangumisearch.py`  
配置文件位于：`run/acg_infromation/config.yaml`

## 交互指令

根据 `bangumi.py` 的精确匹配逻辑，指令分为以下几大类：

### 1. 关键词分类检索（受前缀控制）
搜索指令必须以配置的前缀（默认 `/`）开头，代码会提取分类关键词后面的搜索词：
- `/查询番剧 <番剧名>`、`/番剧查询 <番剧名>`、`/查询动画 <番剧名>`（检索动画类，`cat=2`）
  - 示例：`/查询番剧 命运石之门` 或 `/番剧查询 孤独摇滚`
- `/查询书籍 <书名>`、`/书籍查询 <书名>`（检索漫画/轻小说，`cat=1`）
- `/查询游戏 <游戏名>`、`/游戏查询 <游戏名>`（检索 ACG 游戏，`cat=4`）
- `/查询音乐 <曲名/专辑名>`、`/音乐查询 <曲名>`（检索音乐，`cat=3`）
- `/查询三次元 <人物名>`、`/三次元查询 <人物名>`（检索声优/演员/三次元角色，`cat=6`）

搜索返回候选列表后，在群里直接发送**数字序号**（如 `1`、`2`）即可查看对应条目的精美详情海报；中途如果不想看了，发送 `退出` 即可结束查询会话（会话超时约 3 分钟后也会自动释放）。

### 2. 季度榜单与每日放送（免前缀匹配）
- **季度/热门排行榜**：消息同时包含“本季/季度/本月/top/排行”之一，以及“新番/番剧/动画/bangumi”之一。
  - 示例：`本季新番`、`本月番剧排行`、`本季动画 top10`（支持自定义抓取条数，默认返回 20 条）
- **每日放送时间表**：消息包含“今日/明日/昨日”之一，同时包含“新番/番剧/动画/bangumi/放送”之一。
  - 示例：`今日番剧放送`、`明日新番`
- **B站热门速递**：直接发送 `今日热门`，自动渲染当天的 Bilibili 热门动漫排行榜图。

## 核心配置片段一览（`run/acg_infromation/config.yaml`）

```yaml
acg_information:
  bangumi_query_prefix: "/" # 番剧检索类命令的前缀（默认斜杠 /）
```

## 如果你想修改，应该改哪里？

- **不喜欢打斜杠，想直接发“查询番剧 xxx”？**
  - 把 `bangumi_query_prefix` 改成空字符串 `""` 即可！这样在群里直接发 `查询番剧 进击的巨人` 就能立刻响应啦。
- **AI 智能工具调用**：本插件在 `__init__.py` 导出了 `call_bangumi_search` 工具，当开启 MaiReply 时，大模型也可以在对话中自动为你查询番剧信息。
