# Bangumi 番剧与 ACG 资料查询    

ACG 爱好者必备的追番与资料检索利器！连接 Bangumi 番组计划数据库，无论是查番剧评分、找本季新番列表、翻角色 CV 与制作阵容，还是检索书籍与游戏资料，都能一站式搞定。    

---

## 核心亮点    

- **多类目全网检索**：覆盖番剧、动画、书籍、游戏、音乐以及三次元制作人与声优。    
- **本季新番与热门排行**：自动计算当季月份或自定义 Top 榜单，直观生成高画质海报卡片。    
- **智能排版渲染**：自动截图 Bangumi 权威详情页，清晰呈现评分分布、STAFF 制作人员与剧情简介。    
- **AI 对话 Function Calling 深度联动**：支持自然语言问答时由 AI 自主调取数据，无需死记硬背固定指令。    

---

## AI 智能对话联动 (Function Calling)    

当开启 `mai_reply` 的函数调用能力（`func_calling: true`）后，向机器人提问即可自动触发以下工具：    

| 注册工具名称 | 对应功能说明 | 触发示例 |
| :--- | :--- | :--- |
| `call_bangumi_search` | 搜索 ACG 相关番剧、动画、小说、游戏、音乐或制作人员 | *“帮我查一下葬送的芙莉莲评分怎么样”*、*“看看电锯人动画的信息”* |

大模型会根据对话上下文自动识别需要检索的类目（番剧/书籍/游戏/音乐/三次元）并返回精美的详情渲染图！    

---

## 传统指令触发与交互    

所有指令默认支持前缀（可在配置项中自定义）：    

### 1. 关键词交互搜索    
- **指令格式**：    
  - `/查询番剧 [动画名]` 或 `/番剧查询 [动画名]`（或 `/查询动画 [动画名]`）    
  - `/查询书籍 [轻小说/漫画名]` 或 `/书籍查询 [作品名]`    
  - `/查询游戏 [游戏名]` 或 `/游戏查询 [游戏名]`    
  - `/查询音乐 [歌曲/专辑名]` 或 `/音乐查询 [专辑名]`    
  - `/查询三次元 [人物/声优/监督名]` 或 `/三次元查询 [人物名]`    
- **交互选单流程**：    
  1. 发送例如 `/查询番剧 命运石之门`；    
  2. 机器人将列出匹配的搜索结果编号列表；    
  3. 输入序号（如 `1`、`2`）即可生成该条目的高清长图卡片；输入 `01`、`02` 可查看关联的人物条目；    
  4. 发送 `退出` 可随时终止当前会话检索。    

### 2. 季度新番与排行榜    
- **自然句指令**：    
  - 发送包含 `本季新番`、`本月新番`、`季度动画` 或 `新番排行` 的消息；    
  - 支持指定 Top 范围，例如：`新番top10`、`季度番剧排行top5`；    
  - 机器人会自动获取当季上映作品并生成汇总图。

## 配置文件说明    

相关配置文件位于 `run/acg_infromation/config.yaml`：    

```yaml
acg_information:
  bangumi_query_prefix: "/" # 番剧查询命令前缀，默认为斜杠 /
```
