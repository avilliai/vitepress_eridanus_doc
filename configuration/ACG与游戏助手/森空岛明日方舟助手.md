# 森空岛明日方舟助手

鹰角网络玩家的贴心伴侣！由 `run/anime_game_service/skland.py` 驱动，支持自动化每日打卡、理智监控以及集成战略（肉鸽）深度战绩查询。    

---

## 核心特性

- **一键每日签到**：支持《明日方舟》、《来自星尘》、《终末地》每日自动打卡。    
- **理智与便签监控**：实时查看当前理智恢复进度与基建收益情况。    
- **集成战略深度战绩**：解析傀影、水月、萨米、萨卡兹、界园等各代集成战略通关等级与藏品收藏进度。    

---

## 真实指令列表

### 1. 账号绑定
- 发送 `森空岛绑定` 或 `sklandbind`（支持私聊提交凭证保护隐私）。    

### 2. 每日签到
- 发送 `森空岛签到`、`方舟签到`、`明日方舟签到`、`终末地签到` 或 `sklandsign`。    

### 3. 个人信息与便签
- 发送 `森空岛信息`、`我的森空岛`、`森空岛info` 或 `sklandinfo`。    

### 4. 集成战略（肉鸽）战绩查询
- 发送 `肉鸽信息 <主题名称>` 或 `肉鸽查询 <主题名称>`（亦可使用 `sklandrogueinfo <主题>`）    
- 可选主题包括：`傀影`、`水月`、`萨米`、`萨卡兹`、`界园`    
- **示例**：    
  - `肉鸽信息 萨卡兹`    
  - `肉鸽查询 水月`
