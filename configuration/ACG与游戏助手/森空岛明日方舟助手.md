# 森空岛明日方舟助手

博士，今天也要努力工作哦！理智快要溢出来了，基建里干员也在等着换班呢~

森空岛助手深度整合了鹰角网络森空岛官方数据接口，支持明日方舟多账号凭据绑定、实时理智体力监控、集成战略（肉鸽）战报统计以及每日自动福利签到。

## 源码入口与核心配置

- **代码入口**：`run/anime_game_service/skland.py`
- **后台服务**：`run/anime_game_service/service/skland/`
- **配置文件**：`run/anime_game_service/config.yaml`

服务会为绑定的每位博士在本地建立安全凭据会话，并支持自动刷新凭证。

## 源码里真正支持的触发指令

| 业务分类 | 触发指令 / 别名 | 作用说明 |
| :--- | :--- | :--- |
| **账号绑定** | `森空岛绑定`、`sklandbind` | 唤起私聊绑定引导，引导获取森空岛 Token 并保存 |
| **每日签到** | `森空岛签到`、`方舟签到`、`明日方舟签到`、`sklandsign` | 一键完成森空岛每日签到，自动领取合成玉等福利并回传明细 |
| **实时信息与理智** | `森空岛信息`、`森空岛info`、`我的森空岛`、`sklandinfo` | 查询当前理智存量、理智回满倒计时、基建产出状态与干员工作情况 |
| **肉鸽战略战绩** | `肉鸽信息`、`sklandrogue`、`肉鸽查询`、`查询肉鸽`、`sklandrogueinfo` | 调取集成战略档案，输出历史通关分支、等级与得分卡片 |
| **帮助指引** | `森空岛帮助`、`明日方舟帮助`、`sklandhelp` | 查看完整的指令与绑定帮助 |

## 如果你想做什么，应该改哪里？

1. **绑定提示 Cookie 或 Token 失效**：
   - 重新发送 `森空岛绑定`，根据最新的私聊引导重新获取鹰角网络通行证凭据。
2. **理智回满提醒**：
   - 配合系统定时任务，可与群管或私聊推送联动，在理智即将溢出前发送提醒。
