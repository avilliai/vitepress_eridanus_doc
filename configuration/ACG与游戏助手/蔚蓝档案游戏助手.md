# 蔚蓝档案游戏助手 (Blue Archive)    

内置针对《蔚蓝档案 / 碧蓝档案 (Blue Archive)》的综合游戏攻略与资讯助理，基于 Arona API 与攻略数据库，支持关卡打法、总力战作业以及角色养成图鉴一键调取。    

---

## 核心功能    

- **全关卡攻略与走位图**：输入主线普通/困难关卡代号（如 `12-3`、`H14-3`），瞬间获取 S 评级走位图与路线指南。    
- **角色档案与技能素材**：输入学生名字，即时输出角色技能介绍、装备推荐与专武材料清单。    
- **总力战与大决战机制速览**：提供当期 Boss 机制弱点、装甲属性与推荐编队阵容。    
- **AI 对话 Function Calling 联动**：在自然对话中即可由大模型自主识别并调取游戏攻略。    

---

## AI 智能对话联动 (Function Calling)    

当开启 `mai_reply` 的函数调用能力后，支持通过以下工具实现无需固定指令的自然语言交互：    

| 注册工具名称 | 对应功能说明 | 触发示例 |
| :--- | :--- | :--- |
| `anime_game_service_func_collection` | 游戏服务集合（`m_type="blue_archive"` 查 BA 攻略，`m_type="steam"` 查 Steam 游戏） | *“蔚蓝档案12-3怎么三星过”*、*“给我一份未花的角色培养攻略”* |

---

## 传统指令触发与使用示例    

在群聊中输入以下指令即可：    

- **关卡攻略检索**：    
  - `/攻略 [关卡号]`（例：`/攻略 15-3`、`/攻略 H12-3`）    
  - `/arona [关卡号]`（例：`/arona 20-5`）    
- **角色/活动查询**：    
  - `/攻略 [学生名/活动名]`（例：`/攻略 未花`、`/攻略 白子`）    

机器人将自动生成清晰的高清图文攻略卡片并发送至群内。
