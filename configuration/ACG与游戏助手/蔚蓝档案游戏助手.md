# 蔚蓝档案游戏助手（Blue Archive）

（举起平板电脑，指尖在上面轻巧一划）sensei~ 准备好今天的日程了吗？总力战的作业我已经替你整理好咯！

蔚蓝档案助手整合了 Arona 攻略数据库与各服活动日历，总力战高分作业、学生技能养成材料、未来卡池日程随时随地一键调取。

## 源码入口与核心配置

- **代码入口**：`run/acg_infromation/blue_archive.py`
- **服务驱动**：`run/acg_infromation/service/arona_api.py`
- **代理配置**：走 `run/common_config/basic_config.yaml` 中的全局 `proxy`

## 源码里真正支持的触发指令

源码在 `blue_archive.py` 中严格匹配前缀，以斜杠 `/` 开头：

| 指令格式 | 示例 | 作用说明 |
| :--- | :--- | :--- |
| `/攻略 <关键字>` 或 `/arona <关键字>` | `/攻略 响` | 查询指定学生的技能养成、装备选择与专武建议 |
| `/攻略 <总力战Boss名>` | `/攻略 贯通总力战` | 查询当前总力战机制、借人策略与顶分作业阵容 |
| `/arona 咖啡厅` | `/arona 咖啡厅` | 查询咖啡厅互动与舒适度收益 |
| `/arona` 或 `/攻略`（不带参数） | `/arona` | 弹出使用说明与常见查询分类目录 |
| `/订阅日服` | `/订阅日服` | 订阅日服官方维护公告与新卡池日历推送 |
| `/订阅国际服` | `/订阅国际服` | 订阅国际服活动排期与维护提醒 |
| `/订阅国服` | `/订阅国服` | 订阅国服最新卡池与活动进展 |

> **Yucca 的小贴士**：请一定要带上斜杠 `/` 哦！例如 `/攻略 未花`，代码会精确提取斜杠后面的关键词去查询 Arona 数据库呢~

## 如果你想做什么，应该改哪里？

1. **攻略图片无法加载或超时**：
   - Arona API 接口服务器位于境外，请检查 `run/common_config/basic_config.yaml` 中的 `proxy` 是否开启。
