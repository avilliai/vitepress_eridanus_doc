# 绝区零游戏助手（ZZZ）

（戴上绳匠的酷炫护目镜，跃跃欲试地调试着录像店收银机）新艾利都的街头今天也很热闹呢~ 准备好进入空洞了吗，绳匠？

专门针对《绝区零》（Zenless Zone Zero）设计的专属小工具，支持电量便签查看、绳匠账号绑定与录像店日常监控。

## 源码入口与核心配置

- **代码入口**：`run/anime_game_service/ZZZ.py`
- **服务驱动**：`run/anime_game_service/service/ZZZ/`
- **配置文件**：`run/anime_game_service/config.yaml`

绝区零的数据与米游社体系互通，依赖米游社统一鉴权接口。

## 源码里真正支持的触发指令

| 指令格式 / 别名 | 作用说明 |
| :--- | :--- |
| `zzz绑定` 或 `zzzbind` | 启动绝区零专属绑定流程，调取二维码或引导私聊绑定 |
| `zzz便签` | 配合米游社便签系统，立即渲染绝区零电量、活跃度与代理人调研卡片 |

## 如果你想做什么，应该改哪里？

1. **电量回满提醒**：
   - 绝区零日常与米哈游整体便签互通，在绑定完成后随时发送 `zzz便签` 即可快速查看。
2. **账号切换**：
   - 若有多个账号，在发送 `zzz绑定` 时选择对应 UID 即可切换当前默认关注角色。
