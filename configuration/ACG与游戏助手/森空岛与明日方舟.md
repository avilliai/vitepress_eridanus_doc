# 森空岛与明日方舟助手

鹰角网络玩家看过来！Eridanus 内置的 **森空岛助手**（位于 `run/anime_game_service/skland.py`）支持全自动打卡签到以及博士生涯肉鸽战绩查询！    

---

## 核心特性

- **一键自动签到**：支持明日方舟、来自星尘、终末地每日打卡。    
- **理智与便签监控**：查看当前理智恢复进度与基建收益。    
- **萨米/萨卡兹肉鸽深度战绩**：解析历代集成战略通关等级与藏品进度。    

---

## 真实指令列表

- **账号绑定**：    
  - `森空岛绑定` 或 `sklandbind`（支持私聊提交凭证）    
- **每日签到**：    
  - `森空岛签到`、`方舟签到`、`明日方舟签到`、`终末地签到` 或 `sklandsign`    
- **个人信息与便签**：    
  - `森空岛信息`、`我的森空岛`、`森空岛info` 或 `sklandinfo`    
- **集成战略（肉鸽）战绩查询**：    
  - `肉鸽信息 <主题名称>`（主题可选：`傀影`、`水月`、`萨米`、`萨卡兹`、`界园`）    
  - `肉鸽查询 <主题名称>` 或 `sklandrogueinfo <主题>`    
- **使用帮助**：    
  - `森空岛帮助` 或 `sklandhelp`

## Epic 喜加一免费游戏追踪 (epicfree.py)

白嫖党大欢喜！Eridanus 还会随时帮各位群友盯紧 Epic 商城的免费送游戏动态喵！    

### 触发指令
- **查询当前白嫖游戏**：发送 epicfree 或 epic喜加一    
  - 自动爬取 Epic Games 商店当前限免的游戏封面、原价、截止领取时间及游戏详情。    
- **查看 Epic 助手帮助**：发送 epichelp 或 epic帮助    
  - 调出精美的手绘风格 Epic 菜单卡片。
