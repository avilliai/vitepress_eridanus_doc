# Bangumi 番剧查询与 Galgame 资料库

二次元浓度直接拉满！由 run/acg_infromation/（bangumi.py、galgame.py、blue_archive.py 与 character_identify.py）驱动。    

---

## 一、Bangumi 番剧与角色检索（bangumi.py）

基于 Bangumi（番组计划）API 提供权威的数据支持：    

- **分类检索**：    
  - bgm `<关键词>` 或 bangumi查询 `<关键词>`：综合检索。    
  - 查询番剧 `<关键词>` 或 查询动画 `<关键词>`：专搜动画番剧。    
  - 查询书籍 `<关键词>`：检索轻小说、漫画与单行本。    
  - 查询游戏 `<关键词>`：检索主机/PC/二次元游戏条目。    
  - 查询音乐 `<关键词>`：检索原声集 OST 与单曲。    
- **多轮详情与角色查看**：    
  - 搜索后 Bot 会发送带编号的候选列表图；    
  - 直接发送序号（如 1、2）查看该作品制作企划、分集剧情与评分走势；    
  - 发送带 # 前缀的序号（如 #1）查看关联角色情报！    
  - 发送 退出 即可退出当前查询。    
- **当季新番与排行榜**：    
  - 本季新番、当季番剧：获取当前季度最新上映番剧列表。    
  - 新番排行 top20：获取当期番组热门排行榜单。    
- **B站今日热门**：    
  - 发送：今日热门 即可生成当天的 B 站热门视频/动态大卡片。

## 二、Galgame 资料库与新作推荐（galgame.py）

推 Gal 必备神器，对接批评空间与 VNDB 权威数据库：    

- **随机推荐**：    
  - galgame推荐、gal推荐、随机gal    
- **精准搜索**：    
  - gal精确查询 `<作品名称>` 或 gal精确搜索 `<作品名称>`    
- **模糊搜索**：    
  - gal查询 `<作品名称>`、gal搜索 `<作品名称>`、galgame查询 `<作品名称>`    
- **当期新作速递**：    
  - 本日新作、今日新作、本月新作、昨日新作

## 三、蔚蓝档案攻略与活动订阅（blue_archive.py）

由 Arona API 驱动的老师专属助手：    
- **攻略查询**：    
  - /攻略 `<关卡或角色名>` 或 /arona `<关卡名>`    
  - 示例：/攻略 H11-2、/arona 国服人权    
  - 直接发送 /arona 或 /攻略 查看全部可用分类索引。    
- **各服活动订阅**：    
  - /订阅日服：在当前群开启日服最新活动与卡池更新播报。    
  - /订阅国际服：开启国际服更新提醒。    
  - /订阅国服：开启国服更新提醒。

## 四、AI 动漫角色识别 (character_identify.py)

在群里看到可爱的动漫头像却叫不出名字？    
- **触发指令**：发送 识别 或 @Bot 识别；    
- **发送图片**：Bot 提示后发送需要识别的角色截图；    
- **识别结果**：自动调用 AnimeTrace 模型识别出角色真实姓名、出自哪部动漫/游戏作品，并检测是否为 AI 生成图！
