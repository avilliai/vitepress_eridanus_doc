# 米游社全家桶助手

（戳了戳派蒙软乎乎的脸蛋，数着原石与星琼）原神、崩坏：星穹铁道、崩坏3、绝区零……只要是米哈游全家桶，通通逃不出我的手掌心！

支持原神树脂、星铁开拓力等实时便签卡片渲染、米游币每日任务自动完成、多游戏多角色日常签到与一键福利领取。

## 源码入口与核心配置

- **代码入口**：`run/anime_game_service/mihuyo_club.py`
- **底层驱动**：`service/mihuyo_club/`
- **配置文件**：`run/anime_game_service/config.yaml`

所有玩家的登录凭据（Cookie/Stoken）均由底层安全存储，并支持多角色切换。

## 源码里真正支持的触发指令

### 1. 登录与绑定
- `米游社绑定`、`米游社登录`、`绑定米游社`、`mihuyobind`：启动多端扫码或凭证录入流程。

### 2. 便签与实时体力（以“便签”结尾即可触发卡片渲染！）
- `原神便签`：查看原神当前原粹树脂、洞天宝钱、每日委托进度与周本减半机会。
- `星铁便签`：查看开拓力存量、每日实训活跃度、后勤派遣与历战余响次数。
- `崩坏3便签`：查看体力与爱酱日常提醒。
- `zzz便签`：查看绝区零电量恢复与录像带营业状态。

### 3. 日常福利签到
- `米游社签到` / `mihuyosign`：批量为已绑定的全部米哈游游戏完成签到。
- `米游币签到` / `mihuyocoinsign`：自动完成米游社社区浏览与点赞打卡任务。
- 独立签到：`原神签到`、`星铁签到`、`崩坏3签到`。

### 4. 辅助指令
- `mysgamechange`：切换个人绑定的主展示游戏顺序。
- `米游社帮助` / `mihuyohelp`：弹出米游社帮助菜单。

## 如果你想做什么，应该改哪里？

1. **便签提示登录失效或获取数据失败**：
   - 发送 `米游社绑定` 重新更新 Cookie 或 Stoken。
2. **卡片图片绘制较慢**：
   - 在 `run/system_plugin/config.yaml` 中可开启 `draw_frame.is_lightweight: true` 启用轻量化渲染降低系统开销。
