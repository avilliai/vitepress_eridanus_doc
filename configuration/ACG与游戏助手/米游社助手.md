# 米游社助手

由 `run/anime_game_service/mihuyo_club.py` 强力驱动，支持米家全家桶（原神、崩坏：星穹铁道、崩坏3、绝区零等）的日常签到与实时便签监控。    

---

## 核心特性

- **多账号绑定**：安全绑定米游社 Cookie，支持主副号多凭据。    
- **自动化签到**：一键完成角色福利签到与米游币社区任务。    
- **树脂便签查询**：实时监控体力值、委托任务、洞天宝钱与周本折扣剩余。    

---

## 真实指令一览

### 1. 账号绑定与管理
- **绑定指令**：    
  - 发送 `米游社绑定`、`米游社登录`、`绑定米游社` 或 `mihuyobind`    
  - 依照机器人私聊引导提供专属 Cookie 凭据。    
- **切换默认游戏**：    
  - 发送 `mysgamechange`，可随时切换默认查询的游戏类型（原神 / 星铁 / 绝区零 / 崩坏3）。    

### 2. 每日签到
- **全游戏角色签到**：    
  - 发送 `米游社签到` 或 `mihuyosign`    
  - 也可以直接指定游戏快捷签到：`原神签到`、`星铁签到`、`绝区零签到`。    
- **米游币社区签到**：    
  - 发送 `米游币签到` 或 `mihuyocoinsign`，自动执行浏览与打卡获取社区米游币。    

### 3. 便签监控
- **查询树脂/开拓力/电量便签**：    
  - 发送 `便签`、`原神便签`、`星铁便签` 或 `绝区零便签`    
  - 机器人将生成精美的实时状态卡片，展示当前体力充盈倒计时。    

### 4. 帮助指南
- 发送 `米游社帮助` 或 `mihuyohelp` 获取完整参数说明。
