# Suno 音乐创作工坊

（戴上头戴式耳机，脚尖跟着欢快的节拍轻轻点地）不仅能画画写诗，我还会作曲编曲写歌哦~ 主人想听流行、摇滚还是治愈系纯音乐？

本模块接入了 Suno AI 顶尖音乐大模型。你可以自由指定流派风格、乐器编曲、甚至把随手写的一小段打油诗或者心情碎碎念交给我，几分钟内就能为你现场谱写一首带完整人声演唱的完整单曲！

## 源码入口与核心配置

- **代码入口**：`run/ai_generated_art/suno.py`
- **后台服务**：`service/suno_api.py`
- **配置文件路径**：`run/ai_generated_art/config.yaml`

配置片段展示了 Suno 服务端地址与凭据支持：

```yaml
suno:
  api_url: "http://127.0.0.1:8000" # 本地或自建 Suno API 调度服务地址
  api_key: ""                      # 鉴权 Token（若服务端开启了认证）
```

## 交互指令

采用沉浸式向导对话交互，不需要一次性敲一大长串参数：

| 指令格式 | 作用说明 |
| :--- | :--- |
| `#suno` | 启动音乐创作向导流程 |
| 1. 输入风格 Tags | 机器人提示：“请发送你想要的风格标签~”<br>（例如：`J-pop, anime OST, sweet female vocal`；输入 `1` 则由 AI 自由发挥） |
| 2. 输入歌词/主题 | 机器人提示：“请发送你的歌词或故事主题~”<br>（例如输入自创歌词；输入 `1` 则让 AI 结合风格自动作词） |
| `#ok` | **确认提交生成！** Suno 任务队列开始渲染，完成后以群音频文件或语音直传回群 |
| `#clear suno` | 随时发送 `#clear suno` 可以立刻取消并退出当前音乐向导 |

## 如果你想做什么，应该改哪里？

1. **部署自己的 Suno-API 服务**：
   - 在本地或 VPS 上拉起开源 `suno-api` 容器后；
   - 打开 `run/ai_generated_art/config.yaml`，将 `suno.api_url` 指向你的服务地址。
2. **想要全英文/日系流行风格**：
   - 在风格引导步骤输入 `City Pop, 80s retro, upbeat` 或 `Japanese idol, high energy` 即可精准控制曲风。
