# 九宫格表情包制作

群友们天天斗图是不是都快图穷了？来看看这个大杀器！

只要丢给我一张任何角色的原图，我就能把这个角色精准提炼出 Q 版萌系画风，一口气为你生成一整套 3x3 九宫格的生动贴纸表情包，而且还会自动裁剪切块成独立的小表情发出来哦~

核心代码位于：`run/ai_generated_art/gptimage2_meme_generator.py`  
配置文件位于：`run/ai_generated_art/config.yaml` 的 `gptimage2` 区块

## 源码里真正支持的交互指令

- `/制作表情包` 或 `/表情包制作`
  - 示例：直接在群聊里发送 `/制作表情包`
  - 机器人会提示：“`请发送一张图片作为表情包的参考角色图片（发送 /end 退出）：`”
  - 接着发送一张包含角色形象的图片，系统会自动结合可爱 Q 版模板，生成一张 3x3 的九宫格表情总图，并在后台进行九宫格切图，把 9 张裁切好的独立表情包一张一张发送出来！
- `/end`
  - 如果在制作过程中突然不想做了，发送 `/end` 就可以随时主动退出表情包制作状态。

## 核心配置片段一览（`run/ai_generated_art/config.yaml`）

```yaml
gptimage2:
  base_url: "http://api.apollodorus.xyz/v1"
  apikey: "your_gptimage_key"
  model: "gpt-image-2.5-flare"
  # 表情包画风参考模板路径（内含 9 种经典 Q 版情绪构图）：
  sticker_style_ref: "data/system/sticker_template_3x3.png"
  # 表情包生成分辨率（推荐 1K 或 2K，2K 切出来的单张表情更清晰精美）：
  sticker_resolution: "1K"
  max_retry: 5
```

## 如果你想修改，应该改哪里？

- **切出来的单个表情包感觉有点糊？**
  - 把 `sticker_resolution` 从 `"1K"` 改为 `"2K"`，生成的母图分辨率翻倍，切分出来的表情包边缘和文字都会非常锐利。
- **想定制自己专属的一组表情神态模版？**
  - 替换 `sticker_style_ref` 指向的图片文件，只要保证是一张规整的九宫格排布参考图，大模型就会参考新模板的神态进行迁移合成啦。
