# 衣橱系统与人设锚点（Wardrobe）

衣橱系统是 Eridanus 的**全局角色视觉与穿搭中枢**。它把 Bot 的外貌特征、固定画风、LoRA 权重和每日/场景服装统一收口管理，不再需要在多个插件配置中重复粘贴繁琐的英文 Prompt。

- **核心源码**：`run/wardrobe/wardrobe_manager.py`、`run/wardrobe/sd_prompt.py`
- **配置文件**：`run/wardrobe/config.yaml`

---

## 跨模块联动机制

配置好衣橱后，以下模块会自动读取同一份人设与当前着装：

1. **AI 对话（CoreReply）**：
   - `run/core_reply/service/prompt_builder.py` 会把 Bot 当前穿着注入系统上下文，让 Bot 在聊天中知道自己今天穿什么衣服，并能通过 Function Calling 工具 **`call_change_outfit`** 自主换装。
2. **ComfyUI / SD / GPTImage2 绘图**：
   - **ComfyUI / SD**：当 `is_about_bot=True`（或触发自拍/空间配图）时，自动依次拼装 `character_anchor` + 当前 `current_outfit_tags` + `art_anchor`，并自动提取 `art_anchor` 中的 `<lora:name:strength>` 转为 ComfyUI `LoraLoader` 链式节点。
   - **GPTImage2**：当启用 `gptimage2` 绘制 Bot 本尊（含 `text2img` 与 QQ 空间配图）时，会自动结合 `bot_oc` 设定图与衣橱当前穿搭描述重绘。
3. **QQ 空间自动冲浪**：
   - `run/qq_zone/qzone.py` 已移除自身的冗余绘图与角色设定，发定时早安/晚安及日常动态时统一读取衣橱角色锚点，并根据文案情景自动切换/恢复合适穿搭（如夜间卧室内自拍不叠加贝雷帽或厚外套）。

## 核心配置结构（`run/wardrobe/config.yaml`）

```yaml
enabled: true                      # 总开关：true 启用衣橱联动与自动换装；false 仅使用基础锚点
default_outfit: 默认常服
current_outfit: 默认常服

# 角色外观基础锚点（发色、瞳色、发型、脸型等固定特征）
character_anchor: >-
  1girl, teenager, solo, grey hair, gradient hair, multicolored hair, blue hair,
  light purple-light blue mixed eyes, (Side swept hair:1.6), ahoge, bangs,
  middle long hair, (round face:1.2)

# 画风与轻量 LoRA 锚点（支持直接写 <lora:模型名:权重>，ComfyUI 会自动剥离并接入 LoraLoader）
art_anchor: >-
  (Rella:1.2), (chen bin:1.3), virtual youtuber, (starshadowmagician:1.2),
  masterpiece, extremely detailed, lineart, (hand-drawn:1.3), (sketch:1.2),
  Picasso style, Van Gogh's almond blossoms, <lora:DeniaV1-Nuclear1811-IL:0.3>

# 统一负面提示词
negative_prompt: >-
  lowres, bad anatomy, bad hands, text, error, missing fingers, extra digit,
  fewer digits, cropped, worst quality, low quality, normal quality,
  jpeg artifacts, signature, watermark, username, blurry, nsfw
```

### 服饰库（`outfits_v7`）
内置 72 套覆盖日常私服（`daily`）、四季时令（`seasonal`）、居家睡衣（`sleepwear`）、特色装扮（`special`）、运动（`sport`）和节日（`festival`）的预设服饰。每套服饰均包含：
- `name` & `description`：供 LLM 理解穿搭含义；
- `clothing_tags`：纯英文服装 Tag；
- `no_hat`（可选）：室内/睡衣等不宜戴帽场景标记；
- `full_prompt`：预组装完整参考提示词。

## 对话换装与常见调整

- **如何让 Bot 换衣服？**
  - 在群聊或私聊中直接对 Bot 说（如“帮我换上白色荷叶边睡裙”、“今天去海边穿泳装吧”），LLM 会自动调用 `call_change_outfit` 从服饰库匹配或生成定制穿搭并持久化到 `current_outfit`。
- **想更换 Bot 默认画风或 LoRA？**
  - 直接修改 `run/wardrobe/config.yaml` 中的 `art_anchor` 即可，ComfyUI、SD 与 QQ 空间配图会同步生效。
- **用户指令指定了特殊服饰会和默认常服打架吗？**
  - 当提示词明确包含睡裙、泳装、礼服、制服、旗袍、卫衣等特定服饰关键词时，`comfyui_drawer` 与 `prompt_optimizer` 会自动跳过叠加 `current_outfit`，避免两套衣服冲突。
