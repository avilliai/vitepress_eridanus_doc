# Qwen 通义万相自然语言生图

（托着下巴轻轻哼着歌，指尖在纸上勾勒出一抹水墨飞檐）如果你想要纯正的中式美学、或者想用最接地气的大白话随心所欲画图，通义万相 Qwen-Image 可是个绝佳的选择哦！

该功能基于阿里通义实验室与 ModelScope 社区的 Qwen-Image 架构构建，对长句中文、古风意境以及复杂中文空间描述拥有极强的理解能力，无需绞尽脑汁拼凑英文 Tag 就能画出惊艳大作。

## 源码入口与核心配置

- **代码入口**：`run/ai_generated_art/qwen_img.py`
- **配置文件路径**：`run/ai_generated_art/config.yaml`

配置片段如下：

```yaml
ai绘画:
  # ModelScope 网页端的 Cookie 凭证（用于调用云端生图算力队列）：
  qwen_image_cookie: "your_modelscope_cookie_here"
```

## 源码里真正支持的触发指令

源码在 `qwen_img.py` 中通过严格的前缀判断：

| 指令格式 | 示例 | 作用说明 |
| :--- | :--- | :--- |
| `#qwen <中文自然语言画面描述>` | `#qwen 汉服少女手持油纸伞走在细雨朦胧的江南古镇石桥上，水墨与二次元融合画风，意境悠远` | 提取后面的自然语言长句，提交至云端生成超高清画作 |
| `#qwen <场景设定>` | `#qwen 赛博朋克风格的未来霓虹夜市，街边摊位冒着热气，头戴猫耳耳机的少女在喝奶茶` | 支持现代科幻、写实与国风多风格生图 |

> **语法细节注意**：指令前缀必须是 `#qwen` 且**中间带有一个半角空格**，代码通过切片提取后面的整段提示词！

## 如果你想做什么，应该改哪里？

1. **生图失败提示 Cookie 过期或未登录**：
   - 访问 ModelScope 社区官方生图页面并登录账号；
   - 随手运行一次生图，在浏览器 F12 开发者工具的“网络（Network）”面板中找到对应请求；
   - 复制其中的完整 Request Cookie，粘贴至 `run/ai_generated_art/config.yaml` 的 `qwen_image_cookie` 中。
2. **生成的图片无法在群内展示**：
   - 检查群聊是否开启了严格的图片过滤，或在配置文件中确认是否启用了图片压缩保护。
