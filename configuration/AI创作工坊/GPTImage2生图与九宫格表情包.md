# GPT-Image2 生图与九宫格表情包制作

想要快速为自己的原创角色或者特定动漫角色生成一整套搞怪可爱的 Q 版表情包吗？    
Eridanus 的 gptimage2 模块（位于 `run/ai_generated_art/gptimage2.py` 与 `run/ai_generated_art/gptimage2_meme_generator.py`）就是为你量身定做的神器！    

---

## 核心特性

- **高分辨率生图**：支持 1K / 2K 超清生成，预置画风参考模板。    
- **九宫格表情包自动切分**：自动根据角色特征生成 3x3 表情矩阵，并利用内置图像切片引擎切出 9 张独立的高清表情包直接推送到聊天窗口！    
- **多轮图像编辑模式**：支持进入会话模式连续微调画面。    

---

## 配置文件详解

配置文件位于 `run/ai_generated_art/config.yaml` 的 gptimage2 段：    

```yaml
gptimage2:
  base_url: "http://api.apollodorus.xyz/v1"
  model: "gpt-image-2.5-flare"   # 可选 gpt-image-2.5-flare 或 nano-banana-2
  apikey: "sk-xxxxxxxx"
  sticker_style_ref: "data/system/sticker_template_3x3.png" # 风格参考图
  sticker_resolution: "1K"
  aspect_ratio: "1:1"
  resolution: "1K"
  max_retry: 5
```

## 真实触发指令

### 1. 快速生图与单图生成 (gptimage2.py)
- **指令语法**：    
  - `/生图 <画面描述>` 或 `/gpt <画面描述>`    
- **使用示例**：    
  - `/生图 坐在咖啡馆窗边的戴眼镜猫娘，手里捧着热拿铁`    
  - `/gpt 赛博朋克霓虹街道上的雨中武士`    
- **特殊彩蛋**：    
  - 如果提示词中包含了当前 Bot 的名字（如 `Yucca`），系统会自动标记并追加专属角色特征提示词！    

### 2. 交互式图像编辑模式 (gptimage2.py)
- **发起编辑**：发送 `/图像编辑` 进入交互式微调流程；    
  - Bot 提示：“进入添加模式，请发送文本描述和图像（可多张），全部发送完成后，请发送 /end 提交任务”    
- **提供素材**：在当前会话中直接发送参考图片（1张或多张）以及文字描述（可分多次发送，系统会自动拼接合并）；    
- **提交生成**：发送 `/end` 开始调用 API 渲染，生成后自动发送回群聊；    
- **退出与清理**：完成渲染或异常退出后自动清理用户本地缓存临时文件。    

### 3. 九宫格表情包制作 (gptimage2_meme_generator.py)
- **发起制作**：发送 `/制作表情包` 或 `/表情包制作` 进入九宫格表情包模式；    
  - Bot 会提示：“🎨 已进入表情包制作模式，请发送：1. 参考角色图片（1张） 2. 描述文字（可选，如：生气的、可爱的）。全部发送后，发送 /end 开始制作”    
- **发送参考图与描述**：    
  - 发送 1 张你想要做成表情包的角色立绘/头像/照片（支持发送图片、表情包或引用图片）；    
  - 发送可选的补充描述词（如：傲娇、害羞、委屈、得意的各种日常表情）；    
  - 每次发送素材，Bot 会提示 `已添加`；    
- **开始制作**：发送 `/end`；    
  - 如果还未发送参考图片直接发 `/end`，Bot 会提示：“❌ 你还没有发送参考图片呢。”    
- **生成与切分流程**：    
  - Bot 会根据 `sticker_style_ref` 模板与你提供的角色图，调用图像大模型生成一张高精度的 3x3 角色表情矩阵大图；    
  - 后台使用 OpenCV 统计投影分析算法进行网格行列切片与贴纸轮廓边缘精修（`split_grid_3x3`），完整保留白色外轮廓描边与特效；    
  - 自动将切分好的 9 张表情包逐一发送到当前聊天窗口中！
