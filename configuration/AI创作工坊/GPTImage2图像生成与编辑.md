# GPT-Image2 图像生成与编辑

想要利用高画质扩散大模型为你的角色或构想生成插画？亦或是在现有画作上进行多轮微调与编辑？    
Eridanus 接入了 GPT-Image2 创作管线（位于 `run/ai_generated_art/gptimage2.py`），提供免部署的超快生图与交互式编辑体验！    

---

## 核心特性

- **超高分辨率生成**：支持 1K / 2K 超清分辨率输出，细节细腻层次丰富。    
- **多轮交互式图像编辑**：支持进入会话模式，连续上传多张参考素材图并组合文字要求进行微调。    
- **多模型支持**：无缝对接 `gpt-image-2.5-flare` 与 `nano-banana-2` 等生图模型。    

---

## 配置文件详解

配置文件位于 `run/ai_generated_art/config.yaml` 的 gptimage2 段：    

```yaml
gptimage2:
  base_url: "http://api.apollodorus.xyz/v1"
  model: "gpt-image-2.5-flare"   # 可选 gpt-image-2.5-flare 或 nano-banana-2
  apikey: "sk-xxxxxxxx"
  resolution: "1K"             # 默认分辨率
  aspect_ratio: "1:1"          # 预设画幅比例
  max_retry: 5
```

## 触发指令与使用方式

### 1. 快速单图生成
- **触发指令**：    
  - `/生图 <画面描述>` 或 `/gpt <画面描述>`    
- **使用示例**：    
  - `/生图 坐在咖啡馆窗边的戴眼镜短发少女，手里捧着热拿铁，阳光洒在桌面上`    
  - `/gpt 赛博朋克霓虹街道上的雨中武士，电影质感，超清细节`    
- **特色机制**：    
  - 如果提示词中包含了当前 Bot 的名字，系统会自动识别并追加专属形象特征提示词，保证角色外观的一致性！    

---

### 2. 交互式多轮图像编辑
想要在原有图片基础上做修改？进入交互式编辑模式即可：    

1. **进入编辑模式**：    
   - 发送 `/图像编辑`；    
   - Bot 回复：“进入添加模式，请发送文本描述和图像（可多张），全部发送完成后，请发送 /end 提交任务”    
2. **发送编辑素材**：    
   - 发送 1 张或多张参考图片（支持普通图片、表情包或聊天回复图片）；    
   - 发送对画面的具体修改要求（可以分多条消息发送，系统会自动拼接合并需求）；    
3. **提交渲染**：    
   - 发送 `/end` 触发后端渲染流程；    
   - 渲染完成后自动清理临时缓存并将最终修改图发送到当前聊天窗口中。
