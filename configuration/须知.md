# 部署与安全须知

## 1. 保护你的敏感信息（绝对防泄露！）

各个 `config.yaml` 和 `basic_config.yaml` 里面存放了大量机密凭证：
- 主人的专属 QQ 号码与 Master ID
- 各类大模型与画图平台的 API Key（OpenAI、Claude、Gemini、NovelAI、Suno、心知天气等）
- WebUI 的控制台登录 Token
- B站、米游社、Steam、森空岛等平台的个人登录 Cookie 与 Token

**千万不要把包含了这些机密信息的 YAML 文件推送到任何公开的 Git 仓库（比如 GitHub / Gitee）！** 很多脚本爬虫一天 24 小时都在扫描泄露的 API Key，一不留神你的额度就会被别人偷偷刷光光啦。

## 2. 理解权限等级（别乱给 1000 级！）

Eridanus 内部有一套严格的用户等级体系：
- `0` 级：普通群友与访客
- `10` 级：关注者
- `100` 级：贡献者
- `500` 级：信任者
- `1000` 级：管理员（Master 核心管理）

像黑白名单管理、全群广播通知、强制退群、重启与垃圾回收这类毁灭性指令，代码里都严密卡死了需要 `1000` 级权限。平时千万不要随随便便把不熟悉的人授权到高权限，不然把群玩坏了可别找我哭鼻子~

## 3. 网络环境与代理规范

因为 Eridanus 整合了非常多国际优质二次元与 AI 服务（例如 Google Gemini、NovelAI、Iwara、SauceNAO、Telegram 等）：
- 如果你的部署服务器位于国内大陆网络环境，请一定要在 `run/common_config/basic_config.yaml` 中配置好可用的 `proxy`（HTTP/SOCKS5）。
- 如果网络根本打不通，这些服务就会频繁在后台报连接超时，拖慢机器人响应。
