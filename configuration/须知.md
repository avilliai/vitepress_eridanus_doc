# 配置须知

咿，点进来了呀？在开始控制 Yucca 的各种功能之前，有几件极其重要的事情你必须要知道哦！    
请花两分钟仔细看看这一章，能帮你避开 99% 的掉坑陷阱！    

---

## 1. 配置文件的组织结构

Eridanus 的所有插件都在 `run/` 目录下，采用 **高度模块化的 YAML 配置**：    

| 配置路径 | 功能说明 |
| :--- | :--- |
| `run/common_config/basic_config.yaml` | **全局核心配置**：Master QQ、WebSocket 连接方式、WebUI 端口与密码、日志等 |
| `run/common_config/menu.yaml` | **菜单配置**：`/menu` 与 `/remenu` 图形化菜单的分类、指令显示与排版 |
| `run/common_config/censor_user.yaml` | **用户黑白名单**：全局禁止或白名单 QQ 号码列表 |
| `run/common_config/censor_group.yaml` | **群聊黑白名单**：默认启用/禁用的群号列表 |
| `run/<plugin_name>/config.yaml` | **独立插件配置**：每个插件各自的 API Key、模型名称、触发开关等 |

---

## 2. 关于 API Key 的重要安全提示 ⚠️

::: danger 千万不要把你的配置文件 commit 或推送到公开 Git 仓库！
`run/common_config/basic_config.yaml`、`run/mai_reply/config.yaml`、`run/ai_generated_art/config.yaml` 等文件中会填写你的 **OpenAI / Gemini / Claude API Key**、**Steam API Key**、**WebUI 密码**！    
- **本地提交时必须仔细检查**，不要 `git add .` 一脑门全部提交。    
- 如果不小心 `git add` 了 YAML 文件，可以用 `git reset HEAD <path>` 撤出暂存区。    
:::

---

## 3. 热重载与运行时管理指令

Eridanus 具有极其强大的 **插件热重载系统**！修改了配置或插件代码后，**完全不需要重启 Bot**，直接在 QQ 群或私聊里发送指令即可：    

### Master 专属管理指令

> ⚠️ 以下指令仅限 `basic_config.yaml` 中配置的 `master` QQ 号发送有效：    

- **`/reload all`**：热重载 `run/` 目录下的所有插件与配置！秒级生效，无需断开 OneBot 连接。    
- **`/reload <plugin_name>`**：单独重载某个插件（例如 `/reload mai_reply`、`/reload groupManager`）。    
- **`/status`**：查看 Bot 当前运行状态，包括 CPU 卡片、内存占用、已运行时长、线程数和已加载的插件总数。    
- **`/info`**：查看 Eridanus 系统版本、作者与平台信息。
