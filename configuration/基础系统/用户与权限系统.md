# 用户与权限系统

Eridanus 拥有严谨的分级权限架构与持久化用户档案（存储在 data/database/ManshuoCompatibledData.db）。    
由 `run/system_plugin/user_information.py` 与 `run/system_plugin/api_implements.py` 驱动。    

---

## 1. 权限层级划分

| 权限等级 | 身份标识 | 权限说明 |
| :--- | :--- | :--- |
| **0** | 黑名单用户 | 无法使用任何指令，消息被底层静默丢弃 |
| **1** | 普通用户 (User) | 允许使用大部分娱乐、绘图、查询与基础对话功能 |
| **2** | 关注者 (Follower) | 享有更高的绘图/生成额度与优先队列 |
| **3** | 贡献者 (Contributor) | 允许调用部分高级资源与进阶工具 |
| **4** | 信任者 (Trusted) | 极高额度，免大部分普通风控限制 |
| **10** | 管理员 (Admin) | 拥有群管、黑白名单管理、重载插件权限 |
| **9999** | Master (超级管理员) | 拥有系统关机、配置修改、热重载与底层执行权限 |

## 2. 真实用户指令

- **账号注册**：    
  - 发送：注册    
  - 自动在 SQLite 数据库中初始化用户记录，绑定当前 QQ 与入库昵称。    
- **个人档案查询**：    
  - 发送：我的信息    
  - 查看你的当前权限等级、签到天数、金币积分、当前绑定的所在城市（时区）等。    
- **每日签到**：    
  - 发送：签到    
  - 领取每日积分与连续打卡经验。    
- **绑定与修改所在城市（关键！）**：    
  - 发送：修改城市 `<城市名>`    
  - 示例：修改城市 莫斯科、修改城市 深圳、修改城市 旧金山    
  - **重要意义**：这是跨时区动态定时任务（scheduled_tasks）能够准确在你本地时区清晨叫你起床、深夜道晚安的核心依据！

## 3. 管理员授权指令

管理员可通过以下指令直接为特定用户或群聊调整权限：    
- **指令格式 1（纯文本指定）**：    
  - 授权#`<QQ号>`#`<等级>`：例如 授权#1840094972#10    
  - 授权群#`<群号>`#`<等级>`：例如 授权群#879886836#1    
- **指令格式 2（艾特自然语言）**：    
  - 授权 @群友 用户（设为 1 级）    
  - 授权 @群友 关注者（设为 2 级）    
  - 授权 @群友 贡献者（设为 3 级）    
  - 授权 @群友 信任（设为 4 级）    
  - 授权 @群友 管理员（设为 10 级，仅 Master 可用）

## 4. 快捷互动与群管指令 (api_implements.py)

- **赞我**：发送 赞我，Bot 会自动给你的 QQ 空间/名片点 10 个赞！    
- **改备注**：发送 改备注 `<新备注>` 修改好友在 Bot 上的备注名。    
- **罐头笑声**：发送 罐头笑声，Bot 发送一段搞笑综艺配音语音。    
- **禁言我**：发送 禁言我，主动求罚禁言 60 秒。    
- **我要头衔**：发送 我要头衔 `<头衔名称>`，Bot 会调用协议端接口为你在当前群设置群专属头衔（需 Bot 为群主）。    
- **戳我**（私聊专属）：发送 戳我，Bot 会用 QQ 戳一戳反戳你。    
- **Master 专属操作**：    
  - 换头像：进入换头像流程，随后发送图片即可一键更换 Bot 的 QQ 头像；    
  - 给我管理 / 取消管理：一键设置或撤销当前群的群管理员；    
  - 改群名 `<新群名>`：一键修改当前群聊名称。
