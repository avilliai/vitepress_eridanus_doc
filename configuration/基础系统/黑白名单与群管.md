# 黑白名单与群管系统

为了防止熊孩子爆破或者把机器人拉到乱七八糟的群里，Eridanus 准备了双重保险！    
由    
run/basic_plugin 的黑白名单系统、    
run/groupManager 的自主管理工具以及    
run/character_detection 的敏感角色审核共同维护秩序。    

---

## 一、黑白名单控制（asic_plugin & groupManager）

在    
run/common_config/basic_config.yaml 中，你可以切换全局名单模式：    
- lacklist（推荐）：默认对所有人开放，被拉黑的人或群完全无法触发机器人。    
- whitelist：严格白名单，只有被明确加入名单的人或群才能使用任何功能。    

### 1. 自然语言管理指令（asic_plugin）
仅限管理员或高权限用户执行：    
- **用户名单操作**：    
  - 拉黑用户 `<QQ号>` 或 拉黑 `<QQ号>`    
  - 解黑用户 `<QQ号>` 或 解黑 `<QQ号>`    
- **群名单操作**：    
  - 拉黑群 `<群号>`    
  - 解黑群 `<群号>`    
- **名单查询**：    
  - 查看黑名单 或 查看白名单    

### 2. 快捷管理指令全集（groupManager/self_Manager.py）
支持全局私聊与群聊快捷管控：    
- **黑名单控制**：    
  - /bl add `<QQ号>`：将指定 QQ 加入黑名单    
  - /bl remove `<QQ号>`：将指定 QQ 移出黑名单    
  - /blgroup add `<群号>`：将指定群加入黑名单群    
  - /blgroup remove `<群号>`：将指定群移出黑名单群    
- **白名单控制**：    
  - /wl add `<QQ号>`：将指定 QQ 加入白名单    
  - /wl remove `<QQ号>`：将指定 QQ 移出白名单    
  - /wlgroup add `<群号>`：将指定群加入白名单群    
  - /wlgroup remove `<群号>`：将指定群移出白名单群

## 二、实用群管与系统维护（groupManager）

如果你给机器人在群里上了管理员头衔，她就能帮你自动料理群内事务啦！    

### 1. 入群申请自动审核
- **指令**：加群审核设置 `<审核规则描述>`    
- **效果**：支持自定义加群审核策略，根据设置对新成员进群申请自动同意或拒绝。    

### 2. 紧急退群指令（Master 专属）
- **指定群退出**：    
  - 退群 `<群号>`    
  - /quit < `<群号>` 或 /quit > `<群号>`    
  - 机器会自动退出目标群聊，防止误入无关群组。    

### 3. 精华消息设置与取消
- **设置精华**：引用目标消息并回复 射精 或 设置精华，机器人会自动把该消息推入群精华。    
- **取消精华**：引用已设为精华的消息并回复 取消精华。    

### 4. 消息撤回
- **指令**：引用机器人自己或群友的消息，回复 撤回 或    
ecall。    

### 5. 系统垃圾回收 (/gc)
- **指令**：/gc    
- **说明**：Master 发送后立即触发 Python 底层 gc.collect() 垃圾回收，释放内存占用。    

### 6. 全局广播通知 (Master 专属)
- **指令**：发送    
otice 并在后续流程中输入通知内容，向所有激活群聊广播公告。

## 三、特定梗图与角色审核（character_detection）

由    
rrun/character_detection/nailong_get.py 驱动，防止特定魔性表情包污染群环境：    

- **奶龙审核开关**：    
  - /开启奶龙审核：在当前群开启检测，一旦发现奶龙表情包立即撤回并警告！    
  - /关闭奶龙审核：关闭奶龙检测。    
- **Doro 审核开关**：    
  - /开启doro审核：开启胜利女神 Doro 梗图检测。    
  - /关闭doro审核：关闭检测。
