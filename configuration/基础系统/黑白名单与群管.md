# 黑白名单与群管控制

有可爱的群友，当然偶尔也会有不守规矩的捣蛋鬼嘛。遇到捣乱的家伙，可千万别手软，直接关进小黑屋就好啦。

控制逻辑主要由以下部分协同完成：
- 全局名单过滤：`run/common_config/basic_config.yaml`
- 名单数据持久化存储：`run/common_config/censor_user` 与 `run/common_config/censor_group`
- 交互管理指令：`run/groupManager/self_Manager.py`

## 源码里真正支持的指令

所有名单操作都要求调用者的权限等级达到 `user_handle_logic_operate_level` 或 `group_handle_logic_operate_level`（默认 1000 级 Master）：

### 用户名单管理
- `/bl add <QQ号>`：将指定用户加入黑名单（例如：`/bl add 12345678`）
- `/bl remove <QQ号>`：将指定用户移出黑名单
- `/wl add <QQ号>`：将指定用户加入白名单
- `/wl remove <QQ号>`：将指定用户移出白名单

### 群聊名单管理
- `/blgroup add <群号>`：将指定群加入黑名单（机器人将无视该群）
- `/blgroup remove <群号>`：将指定群移出黑名单
- `/wlgroup add <群号>`：将指定群加入白名单
- `/wlgroup remove <群号>`：将指定群移出白名单

### AI 智能加群审核条件设置
- `加群审核设置 <具体规则要求>`
  - 示例：`加群审核设置 必须说明是通过什么途径找到本群，且字数不能少于10个字`
  - 只有群主或群管理员可以使用！设置后，新用户的加群申请会由 AI 结合该规则全自动判定是否批准通过。
- `加群审核设置`（后面不带任何文字）：清除本群现有的加群审核规则。

### Master 专属系统维护命令
- `/gc`：立即强制执行系统内存垃圾回收并释放无用缓存
- `notice`：主人专用！发送后机器人会提示“下一条消息将被转发至所有群”，紧接着发送的消息会进行全群广播推送
- `退群<群号>`：让机器人主动退出指定群聊

## 配置文件节选（`run/common_config/basic_config.yaml`）

```yaml
# 用户过滤模式：blacklist（黑名单模式，除了名单上的都响应）或 whitelist（白名单模式，只响应名单上的）
user_handle_logic: blacklist
user_handle_logic_operate_level: 1000 # 添加或移出黑白名单所需的操作者权限等级

# 群聊过滤模式：同上，可选 blacklist 或 whitelist
group_handle_logic: blacklist
group_handle_logic_operate_level: 1000 # 群黑白名单所需操作权限等级

邀请bot加群所需权限: 0 # 谁能拉我进群？设为 1000 则只有主人拉群我才进
申请bot好友所需权限: 0 # 谁能加我为好友？
```

## 如果你想做什么，应该改哪里？

- **只想在一个特定私密小群里测机器人，不想让别人私聊或乱拉？**
  - 把 `group_handle_logic` 改成 `whitelist`，然后使用 `/wlgroup add <你的群号>`，这样不在白名单里的任何群哪怕拉了我，我都装作没听见~
- **防骚扰模式：只允许自己加好友和拉群？**
  - 把 `邀请bot加群所需权限` 和 `申请bot好友所需权限` 都从 `0` 改为 `1000`。这样路人加我或者拉群都会被直接拒绝掉，只有 Master 本人操作才行。
