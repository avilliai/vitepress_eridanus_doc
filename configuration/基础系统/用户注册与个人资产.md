# 用户注册与个人资产

不管是跟我聊天还是玩各种小游戏，每个群友都在我的记忆库里有一份专属档案哦。积分、签到天数、好感度、家乡城市…我都帮你记着呢。

主要实现入口位于：
- 入口监听：`run/system_plugin/user_information.py`
- 数据服务与函数集合：`run/system_plugin/func_collection.py`
- 本地配置：`run/system_plugin/config.yaml`

## 源码支持的交互指令

请认准下面的精准触发格式，千万不要自己脑补不存在的冗长句式哦：

| 指令 | 触发格式 | 详细行为与效果 |
| :--- | :--- | :--- |
| **注册** | `注册` | 在数据库中建立个人用户档案。若未开启自动注册，新用户必须先发送该词 |
| **我的信息** | `我的信息` | 查询当前个人的资产卡片，包含积分、好感度、连续签到天数、绑定城市与权限（精确匹配，写“个人信息”可不会触发哦） |
| **签到** | `签到` | 进行每日签到打卡！获取积分奖励，递增连签天数。若开启配置还会附赠塔罗牌面与每日运势 |
| **修改城市** | `修改城市<城市名>` | 修改自己登记的归属地（例如：`修改城市北京` 或 `修改城市上海`）。会直接影响天气查询插件的默认城市哦 |
| **赞我** | `赞我` | 让我给你的 QQ 资料卡点赞！需要操作者权限达到配置中要求的 `send_like` 等级 |

## 配置文件节选（`run/system_plugin/config.yaml`）

```yaml
user_data:
  是否启用签到: true          # 签到功能总开关，不想让群友签到就关掉
  是否启用个人信息查询: true  # 是否允许群友发送“我的信息”查询资产
  签到附带原图: true          # 签到生成的卡片图是否原图发送
  with_taro: true            # 签到卡片是否合成塔罗牌和运势解读
  with_img_backdrop: true    # 签到卡片是否使用精美二次元背景图
  auto_register: true        # 极为重要！收到任意群友消息时是否自动为其在数据库建档
  change_info_operate_level: 0 # 修改城市所需的权限门槛（0级表示大家都能改）
  permit_user_operate_level: 1000 # 授权指令的权限门槛

api_implements:
  nudge:                     # 戳一戳互动设置
    counter_probability: 50  # 被戳时的反击概率（百分比）
    is_Reply_with_meme: true # 反击时是否回一张表情包
    Reply_with_meme_probability: 50
    Reply_with_meme_method: local # 表情包来源：local 本地，url 网络
    Reply_with_meme_local: 'data/pictures/Mface' # 本地表情包所在目录
    replylist:
      - 戳我干嘛呀！
  send_like: 0               # “赞我”功能所需的最低权限（0 为所有人可用）
  send_like_message: '赞你了喵～' # 点赞成功后的回复语
```

## 如果你想修改，应该改哪里？

- **希望群友发消息就能直接玩，不用先傻傻地发“注册”两个字？**
  - 务必保持 `auto_register: true`！这样任何人只要说话，系统就会悄悄为他建立档案，超级省心。
- **签到想要极简纯文字，或者服务器生图太慢？**
  - 把 `with_taro` 和 `with_img_backdrop` 改为 `false`，签到就会省去繁重的卡片渲染与塔罗排版，速度飞快。
- **群友老是乱戳我，我想调戏回去？**
  - 改 `api_implements.nudge.counter_probability`（比如调成 `80` 让反击更频繁），并且可以往 `Reply_with_meme_local` 指定的文件夹丢进你喜欢的沙雕表情包，反击时就会随机抽一张甩他脸上啦。
- **不想让普通群友乱改城市？**
  - 把 `change_info_operate_level` 调大（比如 `10` 或 `100`），这样只有高权限群友才能用 `修改城市` 指令啦。
