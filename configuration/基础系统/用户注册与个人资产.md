# 用户注册与个人资产数据    

Eridanus 拥有完善且线程安全的用户数据中心，记录用户的等级、积分货币、好感度、城市与时区设置等基础属性。    

---

## 核心特性    

- **自动建档与开户**：新用户在群内初次互动或发送注册指令时，自动创建本地数据库档案。    
- **每日签到与资产累积**：支持打卡签到，获取每日金币、经验值奖励并记录连签天数。    
- **城市与时区绑定**：用户可绑定个人常住城市（如北京、东京、莫斯科、旧金山），用于驱动本地化动态定时任务与早晚安推送。    
- **AI 对话 Function Calling 深度联动**：在与机器人的自然聊天中即可完成所有个人资料维护！    

---

## AI 智能对话联动 (Function Calling)    

当启用 `mai_reply` 的工具调用后，大模型可在对话中自主调用以下工具：    

| 注册工具名称 | 对应功能说明 | 触发示例 |
| :--- | :--- | :--- |
| `call_user_data_register` | 自动为新用户创建数据库档案 | *“给我注册一个账号”* |
| `call_user_data_query` | 查询用户等级、积分、好感度与个人信息 | *“查一下我的个人资料和好感度”* |
| `call_user_data_sign` | 每日签到打卡并获取货币奖励 | *“今天还没签到呢，帮我签到”* |
| `call_change_city` | 修改用户所在城市与地理位置（自动推导时区） | *“我搬去旧金山了，帮我改一下城市”* |

---

## 传统指令触发与使用示例    

在群聊中输入以下指令：    
- `/注册`：为当前 QQ 建立用户账户；    
- `/个人信息` 或 `/我的信息`：查看个人等级、当前货币资产与好感度；    
- `/签到`：每日签到打卡，领取货币；    
- `/设置城市 [城市名]`：修改自己的所在城市（例：`/设置城市 莫斯科`）。
