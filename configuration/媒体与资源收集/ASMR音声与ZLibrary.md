喵呼~ 夜深人静睡不着觉，或者想安安静静找本好书看？    
这里有让你瞬间放松颅内高潮的 ASMR 助眠音声系统，以及直通全球最大数字图书馆 Z-Library 的知识宝库。

## 1. ASMR.one 音声检索与助眠 (ASMR)

基于 ASMR.one 接口，支持按 RJ 号、社团名、声优或主题进行智能检索，甚至能直接生成流媒体试听节点：    

### 聊天触发指令

| 指令 | 示例 | 说明 |
| :--- | :--- | :--- |
| `随机asmr` / `随机奥术` | `随机asmr` | 随机抽取一部高分好评助眠音声，提供作品信息与试听直链 |
| `最新asmr` / `最新奥术` | `最新asmr` | 探索近期上架的最新 RJ 作品 |
| `最热asmr` / `热门asmr` | `最热asmr` | 调阅当下最畅销的人气同人音声榜 |

```
用户：随机asmr
Yucca：
🎧 为你挑选了今晚的助眠良伴：
【RJ1029384】猫娘执事的耳语特训 (CV: 某知名声优)
🏷️ 标签: 耳搔 / 舔耳 / 傲娇 / 心音
时长: 01:24:15 | 附带双耳高保真音质试听切片
今晚戴上耳机好好睡个安稳觉吧，不准再胡思乱想啦~
```

### 与 AI 对话与定时任务深度联动
在日常跟我的聊天中，你随时可以说：    
- *“今晚睡前记得给我发个助眠 asmr”*    
- *“每天晚上 11 点给我推个舒服的耳搔音频”*    

我就会直接自动调用 `call_create_schedule_task` 并在里面预置 `call_asmr` 工具，到点自动为你挑选并送达！    

## 2. Z-Library 全球图书检索与极速下载

内置 Z-Library API 协议，让知识获取触手可及：    

### 检索图书

| 指令 | 格式 | 说明 |
| :--- | :--- | :--- |
| `搜书 <书名或作者>` | `搜书 深入理解计算机系统` | 检索 Z-Library 藏书，返回序号、书名、语言、文件格式与文件哈希 |

### 一键下载

在搜索结果中找到心仪的书籍后，直接根据返回的 ID 与 Hash 发起下载：    

| 指令 | 格式 | 说明 |
| :--- | :--- | :--- |
| `下载书 <book_id> <hash>` | `下载书 123456 abcdef` | 后台极速抓取电子书文件（支持 epub、pdf、mobi、azw3），直接发送到聊天中 |

```
用户：搜书 挪威的森林
Yucca：
📚 找到以下图书版本：
1. [10293] 挪威的森林 (村上春树) [EPUB - 1.2MB] - Hash: 8f9a2b
2. [10294] 挪威的森林 (未删节版) [PDF - 4.5MB] - Hash: 3c1e7a
请发送【下载书 ID Hash】即可获取电子书文件！
```
