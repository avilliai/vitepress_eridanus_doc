# ASMR 音声检索与试听

深夜失眠想要听治愈温柔的声优音声助眠？    
Eridanus 接入了 ASMR 在线检索与收听功能（位于 `run/streaming_media/asmr.py`），随时随地为你推荐和试听好听的 RJ 音声作品！    

---

## 核心特性

- **随机音声推荐**：发送简单指令即可随机抽取高评分 RJ 音声专辑。    
- **关键词与 RJ 号搜索**：支持指定声优、社团、作品名称或 RJ 号进行精确查询。    
- **在线试听与直链解析**：自动提取音声分轨试听音频并发送到聊天窗口。    

---

## 配置文件详解

配置文件位于 `run/streaming_media/config.yaml`：    

```yaml
asmr:
  enable: true
  api_base: "https://api.asmr.one"
```

---

## 触发指令与使用示例

- **随机试听**：    
  - 发送：`asmr`、`随个asmr` 或 `随机asmr`    
  - Bot 会随机挑选一部经典音声，发送作品封面、声优信息与分轨试听音频！    
- **精确搜索**：    
  - 发送：`asmr <关键词/RJ号>`    
  - 例如：`asmr RJ01020304` 或 `asmr 治愈助眠 耳骚`
