# ASMR 音声检索与试听

深夜失眠想要听治愈温柔的声优音声助眠？    
Eridanus 接入了 ASMR 在线检索与收听功能（位于 `run/resource_collector/resource_search.py`），随时随地为你推荐和试听好听的 RJ 音声作品！    

---

## 🤖 AI 智能对话联动 (Function Calling)    

当启用 `mai_reply` 的工具调用（`func_calling: true`）时，支持直接在日常聊天中让 AI 检索音声：    

| 注册工具名称 | 对应功能说明 | 触发示例 |
| :--- | :--- | :--- |
| `call_asmr` | 检索 asmr.one 音声作品（支持 RJ 号、社团名、声优与关键词） | *“推荐一部阳向葵的 asmr 音声”*、*“帮我搜一下 RJ01020304”* |    

---

## 核心特性

- **随机音声推荐**：发送简单指令即可随机抽取高评分 RJ 音声专辑。    
- **热门与最新排行榜**：一键浏览全网最新收录与最受好评的热门音声。    
- **在线试听与直链解析**：自动提取音声分轨试听音频并发送到聊天窗口。    

---

## 配置文件详解

配置文件位于 `run/resource_collector/config.yaml`：    

```yaml
asmr:
  enable: true
  api_base: "https://api.asmr.one"
```

---

## 触发指令与使用示例

- **随机音声推荐**：    
  - 发送：`随机asmr`、`随机奥术` 或 `随机奥数`    
  - Bot 会随机挑选一部经典音声，发送作品封面、声优信息与分轨试听音频！    
- **最新收录音声**：    
  - 发送：`最新asmr`、`最新奥术` 或 `最新奥数`    
  - 获取 ASMR 平台最新上架的高清音声作品。    
- **热播榜单音声**：    
  - 发送：`最热asmr`、`最热奥术` 或 `热门asmr`    
  - 获取当前播放量与收藏量最高的热门音声推荐。
