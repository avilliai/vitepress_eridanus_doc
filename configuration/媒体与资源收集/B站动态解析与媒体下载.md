| 注册工具名称 | 对应功能说明 | 触发示例 |
| :--- | :--- | :--- |
| `download_video` | 多平台视频解析与无水印直链下载（B站、YouTube 等） | *“帮我把这个视频下载下来：https://www.bilibili.com/video/BVxxx”* |
| `parse_cloud_music` | 网易云音乐歌曲解析、无损音频提取与分享 | *“解析一下这首网易云音乐链接”* |

## 1. 哔哩哔哩 UP 主动态监听与推送 (Bilibili Dynamic)

支持多群独立监听、实时轮询、自动解析专栏、视频与图文动态并推送到指定群聊。    

### 登录与状态管理

在订阅前，建议让 Bot 登录一个 B站 账号（以获取高清画质与完整动态流）：    

| 指令 | 权限 | 说明 |
| :--- | :--- | :--- |
| /bili login / 站登录 / /bili_login | Master | 获取登录二维码并在群内发送，手机扫码确认后自动保存凭证 |
| /bili login manual | Master | 手动录入 SESSDATA 与 Cookie 凭证（适用于无法扫码的环境） |
| /bili status | 管理员 | 查看当前 B站 账号登录状态与有效时间 |
| /bili search `<关键词>` | 全员 | 搜索指定 UP 主的 UID 信息 |
| /bili help / 站帮助 / 站菜单 | 全员 | 查看 B站 动态订阅功能的详细帮助菜单 |

### UP 主订阅管理

| 指令 | 示例 | 说明 |
| :--- | :--- | :--- |
| /bili add `<UID>` | /bili add 3552663628 | 将指定 UID 的 UP 主添加到当前群的动态订阅列表 |
| /bili remove `<UID>` | /bili remove 3552663628 | 从当前群移除指定 UP 主的订阅 |
| /bili list | /bili list | 查看当前群聊已关注的所有 UP 主名单及最新推送状态 |
| /bili enable `<UID>` | /bili enable 3552663628 | 恢复推送指定 UP 主动态 |
| /bili disable `<UID>` | /bili disable 3552663628 | 暂时挂起指定 UP 主动态推送 |
| /bili resub | /bili resub | 重新激活当前群的动态订阅任务 |

## 2. 万能流媒体与短视频解析 (Link Parsing)

群友在群里分享了短视频或图文链接？不需要点开网页，Eridanus 会自动识别并生成精美排版卡片：    

### 支持平台
- **哔哩哔哩 (Bilibili)**：BV 号、AV 号、b23.tv 短链、番剧影视链接    
- **小红书 (Xiaohongshu)**：无水印图集、笔记视频    
- **抖音 / TikTok**：无水印视频与原声音乐    
- **微博 (Weibo)**：微博正文、图集与视频    
- **推特 / X (Twitter)**：推文推图与内嵌媒体视频    

### 媒体提取与解析开关

- **主动开关解析模式**：    
  - 开启链接解析 或 开始链接解析：进入实时连续解析交互。    
  - end：退出解析交互。    
- **直接提取媒体原文件**：    
  - 下载视频：解析链接并下载原画视频文件直接发到群内或私聊中（大文件自动走本地切片通道）。    
  - 下载图片：提取原链接中的全部无水印高清大图并打包发送。

## 4. 网易云高音质音乐解析与下载 (CloudMusic)

由    
run/streaming_media/cloud_music_parsing.py 驱动的无损音乐解析神器：    

### 触发指令全集
- **指令前缀**：网易云解析、网易云下载、wyy下载、网易云歌曲下载、网易云歌曲解析    
- **指令格式**：`<前缀>` `<网易云歌曲链接或歌名>` [音质品质]    
- **支持音质档位**：    
  - 标准    
  - 极高    
  - 无损    
  - Hi-Res    
  - 高清环绕声    
  - 沉浸环绕声    
  - 超清母带    
- **示例**：    
  - wyy下载 https://music.163.com/#/song?id=xxxx 无损    
  - 网易云下载 稻香 Hi-Res    
- **效果**：    
  - 自动下载高音质音频文件并通过群文件下发；    
  - 同时调用 manshuo_draw 生成包含专辑封面、歌手信息与音质档位的精致卡片！
