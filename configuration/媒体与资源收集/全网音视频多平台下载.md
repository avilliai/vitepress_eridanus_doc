# 全网音视频多平台下载

（抱着臂膀轻哼一声）看到好听好看的音视频想保存下来？别去到处找解析网站吃广告啦，把链接甩给我，分分钟给你扒下来~

Eridanus 的媒体解析由 `youtube.py`、`Link_parsing.py` 以及 `cloud_music_parsing.py` 协同负责，覆盖 YouTube、Bilibili、网易云音乐以及常见短视频链接的音视频嗅探与离线下载。

## 源码入口与核心配置

- **代码入口**：
  - `run/streaming_media/youtube.py`（YouTube 与通用音视频）
  - `run/streaming_media/Link_parsing.py`（多平台短链接与图片嗅探）
  - `run/streaming_media/cloud_music_parsing.py`（网易云卡片与音频解析）
- **配置文件路径**：`run/streaming_media/config.yaml`
- **代理配置**：全局网络请求走 `run/common_config/basic_config.yaml` 的 `proxy`

配置片段如下：

```yaml
网易云卡片:
  enable: false        # 是否绘制网易云歌曲分享精美卡片
  解析自带音频下载url: false # 是否附带音频下载文件（涉及版权，仅私用）

网易云解析:
  enable_proxy: false  # 是否走全局代理
  wyy_prase_url: 'http://nas.manshuo.ink:5000/wyy' # 网易云第三方解析接口

流媒体:
  youtube:
    download_audio_level: 0  # 下载 YouTube 音频所需最低权限等级
    download_video_level: 4  # 下载 YouTube 视频所需最低权限等级（防大文件占用）
```

## 触发指令

| 指令格式 | 示例 | 作用说明 |
| :--- | :--- | :--- |
| `/yt音频 <URL>` | `/yt音频 https://youtu.be/xxxxxx` | 解析并提取 YouTube/B站等音轨，以语音或文件形式发送 |
| `/yt视频 <URL>` | `/yt视频 https://youtu.be/xxxxxx` | 解析并下载对应视频文件回传（受权限等级控制） |
| `下载视频 <URL>` | `下载视频 https://v.douyin.com/xxxx/` | 针对抖音/快手/B站等短视频链接进行去水印解析与文件回传 |
| `下载图片 <URL>` | `下载图片 https://t.bilibili.com/xxxx` | 嗅探动态或图文链接中的全部高清原图打包发送 |
| `网易云下载 <歌曲ID/链接>` | `网易云下载 186016` | 解析指定网易云歌曲并回传音频文件 |
| `网易云解析` / `wyy下载` / `网易云歌曲下载` | 同上 | 匹配网易云音乐关键词快速解析 |

> **注意触发条件**：文档严禁声称“在群里随便发链接机器人就会偷摸自动下载”！源码中对 `下载视频` / `下载图片` / `/yt音频` 有严格的前缀检测，必须显式携带指令。

## 如果你想做什么，应该改哪里？

1. **普通群友无法使用视频下载，提示权限不足**：
   - 打开 `run/streaming_media/config.yaml`；
   - 将 `流媒体.youtube.download_video_level` 调至 `0` 即可放开限制。
2. **YouTube 提取失败或报连接重置**：
   - 检查 `run/common_config/basic_config.yaml` 中的 `proxy` 是否开启，且节点能够访问 YouTube。
3. **网易云点歌只想发好看的分享卡片，不想下载音频文件**：
   - 打开 `run/streaming_media/config.yaml`；
   - 保持 `网易云卡片.enable: true`，并将 `网易云卡片.解析自带音频下载url: false`。
