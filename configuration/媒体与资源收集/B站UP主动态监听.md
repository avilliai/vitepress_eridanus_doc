# B站 UP主动态监听与推送    

支持对 Bilibili UP 主发布的新视频、图文动态、专栏文章进行全天候监控，并在发布后第一时间将高清卡片推送到群聊！    

---

## 核心特性    

- **多群独立订阅**：不同群聊可订阅不同的 UP 主列表，互不干扰。    
- **动态类型全面支持**：覆盖普通视频更新、投稿图文动态、纯文字动态及转发动态。    
- **账号凭据持久化**：支持扫码登录与手动录入 SESSDATA，保障获取高清内容流与长效稳定性。    

---

## 常用指令与权限管理    

以下指令需在群聊中使用：    

### 1. 账号登录与状态    
- `/bili login` 或 `b站登录`：Master 管理员获取登录二维码，手机扫码绑定；    
- `/bili login manual`：Master 手动录入 SESSDATA / Cookie 凭据；    
- `/bili status`：管理员查看当前绑定账号的登录状态与有效期。    

### 2. 订阅与退订 UP 主    
- `/bili sub [UID]`：订阅指定 UP 主（例：`/bili sub 12345678`）；    
- `/bili unsub [UID]`：退订指定 UP 主；    
- `/bili list`：查看本群当前已订阅的 UP 主清单。
