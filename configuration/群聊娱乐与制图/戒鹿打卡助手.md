# 戒鹿打卡助手

（一本正经地敲了敲小黑板，神情格外认真严肃）身体才是革命的本钱！群里的男孩子们，可不要天天沉迷冲动伤了身体呀~ 从今天开始，跟我一起好好自律！

戒鹿助手专为群友身心健康打造，记录每一次毅力的坚持与每日打卡，还能生成连击天数与群内大贤者自律天梯榜。

## 源码入口与核心配置

- **代码入口**：`run/group_fun/lu.py`
- **配置文件路径**：`run/group_fun/config.yaml`

配置片段：

```yaml
today_wife:
  签🦌撤回: true # 打卡消息发送后是否自动撤回防尴尬
```

## 触发指令

源码在 `lu.py` 中对鹿表情与谐音进行了极具趣味的精准监听：

| 指令格式 / 别名 | 作用说明 |
| :--- | :--- |
| `🦌` 或 `打卡🦌` | 记录今天成功忍耐与自律打卡，累积连续自律天数 |
| `戒🦌` | 开启或确认自己的自律打卡誓言 |
| `🦌查询` / `查询🦌` | 查看自己当前的自律连续天数与历史最高坚持纪录 |
| `🦌排行榜` / `鹿榜` | 生成本群的大贤者自律排行卡片，看看谁是真男人 |
| `这倒提醒我了` / `🦌！` / `鹿！` | 破功触发特别语录并重置打卡天数（破戒惩罚） |
| `lu帮助` / `lu菜单` / `🦌帮助` / `🦌菜单` | 调出戒鹿系统的完整指令说明 |

## 如果你想做什么，应该改哪里？

1. **打卡怕被熟人看到太尴尬**：
   - 打开 `run/group_fun/config.yaml`；
   - 将 `today_wife.签🦌撤回` 设为 `true`，Bot 记录完毕后就会秒级撤回消息，神不知鬼不觉！
