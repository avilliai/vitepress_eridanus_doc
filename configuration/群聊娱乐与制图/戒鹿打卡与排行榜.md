# 戒鹿打卡与排行榜

为了群友的身体健康，全自动化的防脱发、戒色打卡系统！    
Eridanus 提供了戒鹿健康管理插件（位于 `run/group_fun/lu.py`），随时随地监督各位群友的日常生活作息！    

---

## 核心特性

- **灵活打卡统计**：支持单发或连发 emoji 打卡（一条消息发多个 `🦌` 自动累加）。    
- **周期排行榜**：支持月度榜单、年度榜单以及全历史统计榜单。    
- **防破戒贞操锁**：一键开启或关闭锁定状态，助你保持专注自律。    

---

## 触发指令与使用方式

- **日常打卡**：    
  - 发送 `🦌`（发几个就记录几次，如 `🦌🦌🦌` 计 3 次）    
  - 或发送 `鹿`、`这倒提醒我了`、`🦌！`    
- **补签与查岗**：    
  - 发送 `查🦌` 或 `查🦌 @群友` 查看个人与他人打卡总数    
  - 发送 `补🦌` 进行打卡补签    
- **自律状态管理**：    
  - 发送 `戒🦌` 进入戒备状态    
  - 发送 `贞操锁 开启` 或 `贞操锁 关闭` 切换自律模式    
- **排行榜与菜单**：    
  - 发送 `🦌排行`、`本月🦌排行`、`今年🦌排行` 查看群内勇士排行榜    
  - 发送 `lu菜单` 或 `🦌帮助` 获取完整指令说明
