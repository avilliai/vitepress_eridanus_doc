# 日常实用工具箱（天气 / 点歌 / 壁纸）

（从口袋里掏出一个万能小布袋）平时聊天除了玩闹，实用的小功能自然也少不了啦！查天气、听音乐、找涩图、搜壁纸，随叫随到~

核心代码位于：`run/basic_plugin/` 系列  
配置文件位于：`run/basic_plugin/config.yaml`

## 交互指令

### 1. 城市天气查询
- `查天气 <城市名称>`
  - 示例：`查天气 北京`
  - 示例：`查天气 上海`
  - 数据由心知天气（Seniverse）提供，返回气温、天气状况、风向与生活出行建议。
  - *(注：如果你之前用“修改城市”绑定过家乡，直接查天气就能享受本地化数据哦)*

### 2. 多源音乐点歌
- `点歌 <歌曲名称>`
  - 示例：`点歌 春日影`
  - 示例：`点歌 负けないで`
  - 自动从音乐平台检索并返回精美的音乐播放试听卡片。

### 3. 壁纸与涩图服务
- `/setu [可选标签]`
  - 示例：`/setu 白丝`
  - 示例：`/setu 萝莉`
  - 示例：`今日 黑丝`（根据 `today_img_list` 配置的今日系列）
  - 从 Lolicon 图库检索并返回高画质插画（受 R18 模式与灰度防封滤镜保护）。

### 4. 帮助菜单与系统维护
- `帮助`、`菜单`、`/help`、`/menu`：呼出 Eridanus 动态渲染的精美全功能导航菜单！
- `/remenu`（Master 专属权限）：手动强制刷新并重新生成动态菜单大图缓存。

## 核心配置片段一览（`run/basic_plugin/config.yaml`）

```yaml
心知天气:
  api_key: "your_seniverse_key"   # 不用配置心知，我们有另一个替代接口。

setu:
  r18mode: true                   # 是否允许 R18 内容
  download: true                  # 是否先下载到本地再发送（开启才能支持灰度滤镜）
  gray_layer: true                # 是否添加轻度防和谐灰度遮罩
  setu_operate_level: 0           # 触发权限等级要求（0 级所有人可用）
  today_img_list:                 # 今日系列触发词列表
    - '巨乳'
    - '贫乳'
    - '萝莉'
    - '黑丝'
    - '白丝'
```

## 如果你想修改，应该改哪里？

- **查天气报错或无响应？**
  - 去 `心知天气.api_key` 填入你自己的心知天气私钥即可。
- **怕群被封，想给涩图加点防护？**
  - 保持 `setu.gray_layer: true`，图片在发送前会自动施加轻微灰度滤镜，有效躲避企鹅的机器视觉封控。
