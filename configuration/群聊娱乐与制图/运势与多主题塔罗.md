# 运势与多主题塔罗牌

（轻巧地闭上眼睛，手指在一叠流光溢彩的卡牌上方轻轻拂过）今天的微风会吹向何方呢？让神秘的塔罗牌和星相来给你一点小小的命运启示吧~

本模块不仅包含传统的综合吉凶每日运势计算，还内置了多套精美主题的塔罗牌抽卡系统，牌面高清无码、附带正逆位权威占卜解读。

## 源码入口与核心配置

- **代码入口**：`run/basic_plugin/basic_plugin.py`
- **配置文件路径**：`run/basic_plugin/config.yaml` 与 `run/system_plugin/config.yaml`

在 `run/system_plugin/config.yaml` 中可配置签到时是否自动附带塔罗占卜：

```yaml
user_data:
  是否启用签到: true
  with_taro: true     # 每日签到时是否自动抽取一张塔罗牌附带运势卡片
  with_img_backdrop: true # 签到卡片是否使用精美背景图
```

## 触发指令

| 触发词 / 指令 | 作用说明 |
| :--- | :--- |
| `运势` | 抽取今日综合运势卡片（吉凶指数、幸运数字、幸运色以及今日宜忌提示） |
| `今日塔罗` | 抽取单张经典韦特塔罗牌，展示正位/逆位并附带运势寓意解读与启示 |
| `抽象塔罗` | 幽默搞怪、充满当代互联网抽象艺术风格的特别版塔罗牌！ |
| `ba塔罗` | 蔚蓝档案（Blue Archive）基沃托斯学生专属塔罗主题牌面！ |
| `bili塔罗` 或 `2233塔罗` | Bilibili 2233 娘看板主题风格专属塔罗牌！ |

## 如果你想做什么，应该改哪里？

1. **不想在每日签到卡片里塞塔罗牌**：
   - 打开 `run/system_plugin/config.yaml`；
   - 将 `user_data.with_taro` 设置为 `false`，签到卡片会变得更加小巧精炼。
2. **每天想占卜很多次**：
   - 运势为每日唯一定格（每个用户每天同一时刻的卦象固定），而塔罗牌则支持随时抽取解惑。
