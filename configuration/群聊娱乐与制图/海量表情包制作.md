# 海量表情包制作

由 `run/meme_generate/meme_generate.py` 驱动，集成数百款热门二次元与网络模因表情包生成引擎！    

---

## 核心特性

- **海量表情模版**：支持经典梗图（如“鲁迅说”、“让我康康”、“摸摸头”、“爬”、“吃”、“打工人”等）。    
- **智能对象识别**：自动根据 @群友 或发送的图片提取头像作为表情包素材。    
- **多图文排版**：支持传入文字参数，自动根据表情模版渲染完美居中或带气泡的文字排版。    

---

## 真实指令列表

- **查看支持的表情列表**：    
  - 发送 `/表情包列表` 或 `/memelist`    
- **制作指定表情**：    
  - 指令格式：`<表情名称> [@群友 或 附带文字]`    
  - 示例：    
    - `鲁迅说 赖哥今天没有赖床`    
    - `摸 @群友`    
    - `吃 @群友`    
    - `让我康康 @群友`    
    - `拍 @群友`    
- **通用制作命令**：    
  - `/制作表情包 <模版名> [参数]`
