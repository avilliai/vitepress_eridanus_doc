# 海量表情包制作（meme-generator）

（从身后掏出一大把表情包甩在桌上）斗图？我可从来没怕过谁！

本插件对接了开源社区著名的 `meme-generator` 图像生成服务，拥有上百种火爆全网的经典表情包模版（摸摸头、吃掉、拍拍、鲁迅说、恐慌、打靶等），支持把群友头像和文字一秒做成动态 GIF 或静态恶搞图！

核心代码位于：`run/meme_generate/meme_generate.py`  
配置文件位于：`run/meme_generate/config.yaml`

## 交互指令

- `meme列表`
  - 示例：直接在群里发送 `meme列表`
  - 返回当前已加载的所有可用表情包关键词列表（长达数百个！）。
- **具体表情包制作触发**：
  - 发送 表情名称 + @目标群友 或附带文字：
  - 示例：`摸 @某群友`（生成经典的摸头 GIF 动图）
  - 示例：`吃 @某群友`（生成一口吞下群友头像的恶搞表情）
  - 示例：`拍 @某群友`（生成拍打群友头像的表情）
  - 示例：`鲁迅说 学医救不了二次元`（生成鲁迅名言大字报风格表情）

## 核心配置片段一览（`run/meme_generate/config.yaml`）

```yaml
pic_path: "./data/pictures/meme_cache/" # 表情包生成缓存目录
meme_generate:
  # meme-generator 服务的 API 地址（请先在本地或服务器启动该后端服务）
  host: "http://127.0.0.1:2233/memes/"
```

## 如果你想修改，应该改哪里？

- **发送了表情指令却提示无法连接或超时？**
  - 检查 `meme_generate.host` 地址是否正确！本功能依赖独立运行的 `meme-generator` Python 图像服务（默认端口 2233），确保该服务已在后台跑起来哦。
