# 伪造转发与发言统计

由 run/group_fun/message_forward_faker.py、
number_speeches.py 与 
record_message.py 驱动。    

---

## 1. 消息伪造与合并转发 (Message Forward Faker)

生动还原聊天记录的吃瓜神器！支持多用户、多段话、表情与图片。    

### 指令语法
- **帮助信息**：发送 伪造消息 或 伪造帮助 查看语法教程。    
- **基础伪造语法**：    
  - 前缀：伪造 或 伪造转发    
  - 格式：伪造 @群友A 内容1 | @群友B 内容2 | @群友A 内容3    
  - 分隔符支持中文 ｜ 或英文 |。    

### 伪造内容支持
- **纯文本**：直接输入文字。    
- **图片**：直接在内容后附带图片，或输入图片外链。    
- **艾特用户**：输入 @某人 或 QQ 号自动抓取其头像与名片。

## 2. 群发言统计与逼话王排行 (Number Speeches)

精确统计群友发言频率，谁是潜水员谁是大水怪一清二楚！后台异步批量入库，既省性能又精确记录每一位群友的水群战绩喵。    

### 核心查询指令
- **日榜（今日逼话王）**：    
  - 支持指令：今日发言榜、本日发言排行、每日逼话王、今日bb排行、今日壁画王    
- **周榜（本周逼话王）**：    
  - 支持指令：本周发言榜、本周发言排行、本周逼话王    
- **月榜（月度大水怪）**：    
  - 支持指令：本月发言榜、月度发言榜、当月发言排行、月度逼话王    
- **年榜（年度话痨终极大奖）**：    
  - 支持指令：今年发言榜、年度发言榜、年度发言排行、今年逼话王    
- **历史回溯与个人查询**：    
  - 回溯前一天/上个月：昨日发言榜、昨日发言排行、上月发言排行、上个月逼话王    
  - 个人战绩查询：我的发言、我的发言次数（调出自己专属的水群活跃度与排名）

## 3. 群友怪话与名言入典 (Record Message)

记录群友的黑历史和逆天言论，生成精美语录卡片！    

- **语录入典**：    
  - 回复群友的某条消息并发送：记录消息、消息记录 或 入典。    
  - 系统会自动提取发言者昵称、头像和文本内容，排版渲染成高质量名言卡片保存入库！    
- **抽取怪话**：    
  - 发送：今日怪话、今日语录、群友怪话 或 群友语录 随机抽取一张历史怪话卡片。    
  - 发送：今日怪话 @群友 专属抽取该群友说过的逆天名言！    
- **清理语录**：    
  - 回复 Bot 发出的语录图片并发送：删除、清理 或 删掉，即可将其从数据库移除。
