# 消息伪造转发（聊天记录生成器）

“群友到底有没有说过这句话不重要，重要的是截图和转发记录里有~”

想要在群里整蛊搞笑、编排小剧场段子？消息伪造插件能将你输入的角色 QQ、昵称与内容，全自动打包生成真实度 100% 的合并转发聊天记录节点卡片！

## 源码入口与核心机制

- **代码入口**：`run/group_fun/message_forward_faker.py`
- **渲染原理**：利用 OneBot 标准的多节点合并转发协议（`node` 消息段），动态抓取对应 QQ 的官方头像与昵称组合封包。

## 源码里真正支持的触发指令

指令格式要求严格以 **`伪造消息 `**（后面带一个空格）开头，多段发言之间使用竖线 `|` 进行切分：

```text
伪造消息 <QQ号或@用户> <内容> | <QQ号或@用户> <内容> | ...
```

### 真实使用示范

1. **通过 QQ 号与纯文本**：
   ```text
   伪造消息 10001 大家好，今天全场消费由我买单！ | 10002 真的假的？那我点两只帝王蟹！
   ```
2. **直接 @ 群成员**：
   ```text
   伪造消息 @张三 今天的晚饭我请客！ | @李四 好耶！
   ```
3. **帮助菜单**：
   - 发送 `伪造消息`（不带参数）或 `伪造帮助`：查看详细语法格式说明。

> **Yucca 的安全红线提醒**：虽然生成出来的合并转发记录跟真的一模一样，但请大家在群里仅限友善玩梗搞怪哦，绝对不可以用来传播谣言或用于任何违法侵权活动呢！
