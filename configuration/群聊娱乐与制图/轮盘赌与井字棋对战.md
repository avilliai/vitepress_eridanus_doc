oulette.py、
oulette_plus.py 与 	ictactoe.py 驱动。    

---

## 1. 经典轮盘赌 (Roulette)

最简单粗暴的俄罗斯轮盘赌，谁是天选之子？    

- **发起对决**：    
  - 发送：轮盘赌    
- **规则机制**：    
  - 左轮手枪 6 发弹巢，随机装入 1 发实弹；    
  - 扣动扳机，中弹者当场获得防沉迷禁言大礼包！    

---

## 2. 恶魔轮盘：进阶道具决斗 (Roulette Plus)

还原《Buckshot Roulette》（恶魔轮盘赌）的深度博弈玩法！包含血量、随机弹药（实弹/空包弹）与多样化功能道具！    

### 发起与加入
- 决斗开始：发起一场恶魔轮盘决斗房间。    
- 加入决斗：其他群友加入对决（双人或多人对局）。    
- 决斗规则：查看游戏操作指引与道具效果表。    
- 决斗状态：查看当前弹仓剩余子弹数、各玩家生命值与手牌道具。    
- 决斗结束：强行终止当前游戏局。    

### 回合操作与道具使用
轮到你的回合时可以执行：    
- **射击目标**：    
  - 射击 @群友：将枪口对准对手扣动扳机！若是实弹对方扣血，若是空包弹轮换回合。    
  - 射击自己：将枪口对准自己扣动扳机！若是空包弹，你将**额外获得一个行动回合**！若是实弹则自己扣血。    
- **使用道具**：    
  - 使用 锯子：本发实弹伤害翻倍（伤害变为 2 点）。    
  - 使用 手铐：锁住对手，跳过对手的下个回合。    
  - 使用 放大镜：偷看当前枪膛内的这一发子弹是实弹还是空包弹。    
  - 使用 啤酒 / 使用 饮料：退掉当前膛内的一发子弹，或回复 1 点生命值。    
  - 使用 香烟：恢复 1 点生命值。

## 3. 井字棋对战 (TicTacToe)

益智对弈，三连定胜负！    

- **创建棋局**：    
  - 发送：创建棋局（默认先手，Bot 会打印当前空棋盘与房间号）。    
- **加入棋局**：    
  - 发送：加入棋局 `<房间号>`。    
- **下子对弈**：    
  - 发送：落子 `<1-9>`（九宫格键盘数字键对应棋盘格子位置）。    
- **棋局管理**：    
  - 棋局信息：重新打印当前棋盘对局状态。    
  - 退出棋局：主动投降退出。    
  - 删除棋局：清理废弃棋局房间。
