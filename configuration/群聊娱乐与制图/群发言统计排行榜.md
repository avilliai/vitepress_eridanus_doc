# 群发言统计与水群排行榜

（托着腮帮子，翻了翻厚厚的群聊小账本）一天到晚到底是谁在群里疯狂摸鱼水群？谁才是名副其实的“大水怪”和“逼话王”？让我翻开小账本瞧瞧！

发言统计模块在后台默默记录群友的每一条发言，以异步批量队列写入 SQLite 数据库，并随时能为你生成精美的发言频次排行榜卡片。

## 源码入口与核心配置

- **代码入口**：`run/group_fun/number_speeches.py`
- **数据落盘**：`data/db/` 下的发言历史数据库
- **绘图框架**：`run/system_plugin/config.yaml` 的 `draw_frame`

## 触发指令

指令由**时间范围词**与**排行榜关键词**自由拼装构成，完全支持自然语言习惯：

| 时间范围词 | 排行榜关键词 | 示例指令组合 |
| :--- | :--- | :--- |
| `今日`、`每日`、`本日` | `发言排行`、`发言次数`、`bb次数`、`bb排行`、`b话王`、`逼话王`、`壁画王` | `今日发言排行`、`今日发言榜`、`今日逼话王`、`今日bb排行` |
| `昨日` | 同上 | `昨日发言排行`、`昨日逼话王` |
| `本月`、`当月`、`月度` | 同上 | `本月发言排行`、`本月逼话王` |
| `上月`、`上个月` | 同上 | `上月发言排行`、`上月逼话王` |
| `今年`、`年度` | 同上 | `今年发言排行`、`年度逼话王` |

发送指令后，机器人会回复：“`收到查询指令，请耐心等待喵`”，随后汇总数据库中当前群所有成员的发言频次，渲染出高排名的发言榜卡片！

## 如果你想做什么，应该改哪里？

1. **排行榜图片渲染优化**：
   - 在 `run/system_plugin/config.yaml` 中设置 `draw_frame.is_lightweight: false` 可获得更精美的高清榜单大图。
2. **数据保留时间**：
   - 定期数据库维护由系统底层自动执行，确保海量发言记录也不会拖慢查询响应。
