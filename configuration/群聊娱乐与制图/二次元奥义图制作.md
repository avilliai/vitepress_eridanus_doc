# 二次元奥义图制作

“我的回合！抽卡！以群友之名，降临吧——终极奥义！”

奥义图制作插件能够将群友的头像、自定义昵称以及震撼的必杀技台词，一键合成为动漫对决风格的必杀卡牌与奥义大招特写海报。无论是在群聊里对决对线，还是整蛊做表情包，牌面瞬间拉满！

## 源码入口与核心机制

- **代码入口**：`run/entertainment/` 与 `run/group_fun/func_collection.py`


## 源码里真正支持的触发指令

| 指令格式 | 示例 | 作用说明 |
| :--- | :--- | :--- |
| `奥义图` | `奥义图 @群友 必杀大招名称` | 抓取被艾特群友的头像与指定招式名，合成专属二次元必杀海报 |
| `奥义生成 <招式名>` | `奥义生成 究极摸鱼冲击波` | 为自己生成一张包含当前头像与必杀技名称的酷炫特写卡 |

## 如果你想做什么，应该改哪里？

1. **生成的图片文件太大，群里加载很慢**：
   - 打开 `run/system_plugin/config.yaml`；
   - 将 `draw_frame.is_lightweight` 设为 `true`，启用轻量压缩优化。
2. **头像拉取偶尔失败**：
   - 确保 Bot 拥有正常访问腾讯头像 CDN（`q.qlogo.cn`）的网络通路。
