# 俄罗斯轮盘赌决斗

（转动着左轮手枪的弹巢，发出“咔哒咔哒”清脆的金属撞击声）六个弹巢，一颗实弹……赌上今天谁在群里女装的命运，敢不敢把枪口对准自己的太阳穴扣下扳机？

经典的群内刺激博弈小游戏！支持多人轮流开枪、装弹重置、对决金币结算以及生动戏剧化的战败处决小作文播报。

## 源码入口与核心机制

- **代码入口**：`run/group_fun/roulette.py` 与 `roulette_plus.py`
- **惩罚机制**：与禁言群管系统或个人积分金币打通

## 触发指令

| 指令格式 | 作用说明 |
| :--- | :--- |
| `轮盘赌` / `装弹` | 初始化一把左轮手枪，装填 1 颗子弹并打乱弹巢，开启全新决斗局 |
| `开枪` | 拿起手枪向自己扣动扳机！<br>• 如果是空膛：发出“`咔哒...（安全）`”，换下一位群友；<br>• 如果中弹：伴随着“`咔嗒...砰！`”的巨响，系统将输出生动惨烈的战败小作文，并将弹巢状态重置 |
| `轮盘赌帮助` | 查看对决规则、连胜纪录与胜负奖励 |

> **Yucca 的俏皮提醒**：运气不好的时候可不要怪我装的子弹太准哦~ 连续躲过五枪的人才是真正的幸运天命之子！

## 如果你想做什么，应该改哪里？

1. **中弹后执行自动禁言惩罚**：
   - 可在 `run/system_plugin/config.yaml` 或权限管理中开启对群管协议的对接，赋予 Bot 对应的群管理员头衔即可生效。
