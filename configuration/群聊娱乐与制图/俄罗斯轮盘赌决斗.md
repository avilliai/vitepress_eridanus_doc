# 俄罗斯轮盘赌决斗

紧张刺激的左轮手枪决斗！输掉的人可是要接受禁言惩罚的哦~    
Eridanus 内置了经典轻量版与进阶道具版俄罗斯轮盘赌（位于 `run/group_fun/roulette.py` 与 `run/group_fun/roulette_plus.py`）！    

---

## 核心特性

- **经典纯运版**：装入随机子弹，扣动扳机，中弹者直接随机禁言！    
- **进阶道具对决版**：支持双人或多人对决，包含放大镜、锯子、饮料、手铐等逆转战局的战术道具！    

---

## 触发指令与玩法流程

### 1. 经典快速模式
- 发送：`轮盘赌`    
- Bot 装填子弹并立即判定，命中者直接禁言！    

### 2. 进阶战术决斗模式
1. **发起与加入**：    
   - 发送 `决斗开始` 发起一场决斗邀约；    
   - 对手发送 `加入决斗` 进入对战房间；    
2. **决斗操作**：    
   - 发送 `射击 @对手` 对对手扣动扳机；    
   - 发送 `射击自己` 对自己扣动扳机（如果是空包弹则获得连续行动回合！）；    
   - 发送 `使用 <道具名>`（如 `使用 放大镜` 查看枪膛内当前子弹类型）；    
3. **状态与结束**：    
   - 发送 `决斗状态` 查看双方生命值与剩余道具；    
   - 发送 `决斗规则` 查看道具效果与得分规则；    
   - 发送 `决斗结束` 强行终止当前战局。
