# 娶群友与后宫管理

群聊日更的核心灵魂，谁才是你命中注定的群友？    
Eridanus 内置了玩法丰富的娶群友与后宫管理系统（位于 `run/group_fun/wifeyouwant.py`），支持娶群友、透管理、离婚以及好感度排行！    

---

## 核心特性

- **每日群老婆随机抽取**：每日零点刷新，支持按数量连抽（`今日老婆 3个`）。    
- **身份专属互动**：支持精准指定群主、管理员或群友进行互动。    
- **后宫好感度羁绊**：长期记录群友之间的互动频次与好感度天数。    

---

## 配置文件详解

配置文件位于 `run/group_fun/config.yaml`：    

```yaml
today_wife:
  今日老婆: true
  wifePrefix: "透"      # 互动触发前缀
  仅热门群友: true       # 是否仅从活跃群友中抽取
```

---

## 触发指令与使用方式

### 1. 今日老婆与群友抽取
- `今日老婆` 或 `今日群友`（每日一次专属缘分）    
- `今日老婆 3个` / `今日群友 5位`（支持批量抽取多位群友）    
- `今日群主` / `今日管理`（定向抽取群管理层）    

### 2. 趣味互动与后宫维护
（在配置文件预设的前缀下生效）：    
- `透群主`：对群主发起专属互动    
- `透管理`：对管理员发起互动    
- `透群友 @群友` 或 `娶群友 @群友`：将指定的群友纳为后宫    
- `离婚`：解除与当前后宫群友的关系    
- `涩涩记录`：查询历史互动与羁绊统计
