# 娶群友与后宫管理

群聊日更的核心灵魂，谁才是你命中注定的群友？    
Eridanus 内置了玩法丰富的娶群友与后宫管理系统（位于 `run/group_fun/wifeyouwant.py`），支持娶群友、透管理、离婚以及好感度排行！    

---

## 核心特性

- **每日群老婆随机抽取**：每日零点刷新，支持按数量连抽（`今日老婆 3张`，上限 5 张）。    
- **身份专属互动**：支持精准指定群主、管理员或指定群友进行互动。    
- **后宫羁绊与好感统计**：长期记录群友之间的互动频次、好感天数与涩涩记录。    
- **趣味文案 API 集合**：内置舔狗日记、网抑云热评、每日一言等随缘语录。

配置文件位于 `run/group_fun/config.yaml`：


## 触发指令与使用方式

### 1. 全局免前缀抽取指令
以下指令无需添加前缀，群内直接发送：    
- **抽取今日老婆**：    
  - `今日老婆` 或 `今日群友`：每日一次专属缘分，随机为你挑选一位群友作为今日老婆并配发精美二次元美图！    
  - `今日老婆 3张` / `今日老婆 3个` / `今日老婆 5位`：批量抽取多张（支持指定 1~5 张，超过 5 张会被系统吐槽“数量过多，渣男”）。    
- **定向抽取身份角色**：    
  - `今日群主`：定向抽取群主卡片。    
  - `今日管理`：定向抽取当前群管理员卡片。    
  - `今日群友 @某人`：为指定群友抽取今日配对卡片。    

### 2. 后宫互动指令（受 wifePrefix 前缀控制）
默认前缀为 `/`（若在配置文件中将 `wifePrefix` 改为其他字符或清空，则以对应前缀触发）：    
- `/透群主`：对群主发起专属互动。    
- `/透管理`：对管理员发起互动。    
- `/透群友 @群友` 或 `/透 @群友`：对指定的群友发起趣味互动。    
- `/娶群友 @群友`：将指定的群友正式纳为后宫（若已有伴侣再次尝试娶他人，会被系统提醒“渣男！吃着碗里的想着锅里的！”）。    
- `/离婚`：解除与当前后宫群友的关系，恢复单身自由身（“离婚啦，您现在是单身贵族咯~”）。    
- `/今日群主`：以前缀方式调用群主互动。    
- `/色色记录` 或 `/涩涩记录`：查询本周、本月或年度与群友的互动羁绊历史。    

### 3. 随缘治愈与趣味句库 (内置文本 API)
群内直接发送关键词，Bot 会调用内置开放接口返回趣味文案：    
- `每日一言`：获取每日随机唯美一言。    
- `emo时刻`、`emo了` 或 `网抑云`：生成伤感扎心的深夜网抑云文字。    
- `wyy评论` 或 `网易云评论`：调取网易云音乐热门金评。    
- `舔狗日记`：随机生成一段令人落泪的卑微舔狗日记。
