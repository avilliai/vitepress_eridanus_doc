# 娶群友与戒鹿管理

群内社交生态天花板！由 run/group_frun/wifeyouwant.py、lu.py 与 pighub.py 驱动。    

---

## 1. 娶群友与群内人际关系 (WifeYouWant)

每天一次，看看谁才是你今天命中注定的群友 CP！    

### 核心互动指令
- **抽取今日老婆**：    
  - 今日老婆、今天的老婆 或 今日群友：随机抽取一名在线群友作为今日专属老婆！    
  - 多选模式：今日老婆 3张 或 今天老婆 2个（最多支持同时抽取 5 位）。    
- **特定身份抽取**：    
  - 今日群主：把群主当成今日专属对象。    
  - 今日管理：抽取群管理员作为今日专属对象。    
- **透群友互动**：    
  - 发送：透 @群友 或 透群友、透群主、透管理    
  - 系统会自动判定好感度与互动结果，记录亲密度统计并适时触发撤回保护。    
- **色色记录排行榜**：    
  - 本周色色记录、本月色色记录、本日色色记录 或 年度色色记录    
  - 查询群里“透群友最多的人”以及“被透最多的人”，榜首还将附带专属荣誉大头像展示！

## 2. 戒鹿修行管理系统 (Lu)

赛博修心，远离低级趣味！群友自律打卡神器。    

### 打卡与操作指令
- **打卡破戒**：    
  - 发送：鹿、鹿！、🦌！ 或 这倒提醒我了 记录一次破戒。    
  - 还可以连发多个 Emoji（如 🦌🦌🦌）一次性记录多次。    
  - 艾特代打卡：@群友 鹿。    
- **正向打卡**：    
  - 戒鹿：打卡记录坚持清心寡欲的天数。    
- **贞操锁系统**：    
  - 贞操锁 开启 / 贞操锁 锁定：为自己佩戴赛博贞操锁，锁定期间禁止违规打卡！    
- **补签与查验**：    
  - 查鹿 或 @群友 查鹿：查看自己或指定群友的历史修行数据与破戒次数。    
  - 补鹿：补录遗漏的打卡记录。    
- **查看菜单**：    
  - 发送：lu菜单、lu帮助、🦌菜单 或 🦌帮助。    

### 榜单与统计查询
- **本月榜单**：发送 🦌排行、🦌排名 或 本月鹿排行。    
- **年度榜单**：发送 今年鹿排行 或 年度🦌排名。    
- **历史总榜**：发送 全部鹿排行、总共🦌排名。

## 3. 今日小猪 (PigHub)

测测你今天的猪猪形态！由 pighub.py 驱动：    
- **个人检测**：发送 今日小猪、今天是什么小猪、今天我是什么猪。    
- **指定群友**：发送 今日小猪 @群友 看看群友今天是什么可爱的小猪仔。    
- **随机小猪图**：发送 随机小猪、随机猪猪、随机红猪。
