# 娶群友互动系统（后宫与好感）

“今天又想在群里抓哪个倒霉蛋当老婆啦？”

每天群里最热闹的传统保留节目！随机抽取一位群友成为今日天命伴侣，还能选出今日群主、今日管理和今日萝莉，更有俏皮的互动玩法~

核心代码位于：`run/group_fun/wifeyouwant.py`  
配置文件位于：`run/group_fun/config.yaml` 的 `today_wife` 区块

## 交互指令

- `今日老婆` 或 `今天老婆`：从当前群成员中随机抽取一位作为你今天的老婆，附带一张精美二次元萌图
- `今日老公`：抽取今日天命老公
- `今日萝莉`：抽取群内专属萝莉
- `今日群主` / `今日管理` / `今日群友`：随机钦定今日荣誉头衔
- **透群友互动系列**（受配置的 `wifePrefix` 前缀控制）：
  - 示例：`/透群友 @某人` 或 `/透老婆`
  - 发起群友轻度调戏互动，系统会自动反馈趣味互动小剧情。

## 核心配置片段一览（`run/group_fun/config.yaml`）

```yaml
today_wife:
  wifePrefix: "/"          # 透群友系列指令的前缀（默认斜杠 /）
  今日老婆: true           # 今日老婆总开关
  今日老公: true           # 今日老公总开关
  今日萝莉: true           # 今日萝莉总开关
  透群友撤回: true         # 互动结果是否在若干秒后自动撤回，防止刷屏
  仅热门群友: false        # 若设为 true，则只从近期活跃发言的群友中抽取老婆，避免抽到潜水僵尸号
  is_at: true              # 抽到谁时是否在消息里 @ 其本人
  api:                     # 附带二次元配图的随机图源 API 列表
    - 'https://sese.iw233.top/iapi.php?sort=random'
```

## 如果你想修改，应该改哪里？

- **老是抽到三年没说过话的死人群友？**
  - 把 `仅热门群友` 改为 `true`！这样只有最近在群里活跃聊过天的群友才会被抓进老婆候选池哦。
- **怕群消息太乱，想让互动消息发出来几秒后消失？**
  - 保持 `透群友撤回: true` 即可，到时间系统会自动撤回，非常清爽。
