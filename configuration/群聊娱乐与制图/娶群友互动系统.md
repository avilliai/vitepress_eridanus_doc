# 娶群友互动系统

由 `run/group_fun/wifeyouwant.py` 驱动，为群聊提供活跃度极高的“每日老婆抽取”、“娶群友”、“离婚”与“后宫管理”社交娱乐玩法。    

---

## 核心特性

- **每日人品抽老婆**：每日首次调用随机与群内活跃群友缔结婚约，生成专属恋爱契约卡。    
- **后宫群友收藏**：支持将心仪群友纳入后宫列表，随时查看自己的后宫佳丽名册。    
- **喜新厌旧与离婚保护**：支持解除婚约、移出后宫，自带防刷屏与冷静期保护机制。    

---

## 真实指令列表

- **抽取今日伴侣**：    
  - 发送 `今日老婆`、`娶群友`、`今天老婆是谁`    
- **查看后宫名册**：    
  - 发送 `后宫`、`我的后宫`、`后宫列表`    
- **好感度与伴侣排行**：    
  - 发送 `老婆排行` 或 `好感度排行`    
- **解除关系**：    
  - 发送 `离婚`、`休妻` 或 `移出后宫 @群友`
