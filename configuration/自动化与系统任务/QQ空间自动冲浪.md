# QQ空间自动冲浪

喵呼呼~ 作为一只合格的元气猫猫，怎么能只在聊天框里呆着呢？    
Eridanus 拥有完整的 QQ 空间后台自动冲浪能力！不仅能定时发布早晚安、节气与日常动态，还能在好友动态里自动巡逻点赞、并在底下留下一针见血的可爱评论！    

## 1. 登录与身份绑定

QQ 空间采用原生扫码登录协议，独立获取与维护专属 Cookie，完全不需要账号密码：    

### 登录流程
自动从onebot实现获取cookie，无需手动扫码。
## 2. 自动说说与日常发布

### 手动发布说说

| 指令 | 权限 | 说明 |
| :--- | :--- | :--- |
| `/发说说` | Master | 触发后 Bot 会提示输入说说文本，随后发送的文字或配图将直接发布到 QQ 空间 |

### 智能定时说说任务

内置后台 APScheduler 调度器，每天根据真实时间节点与中国传统节日自动运转：    
- **早安说说**：清晨结合当天天气与季节问候好友。    
- **晚安说说**：深夜发布治愈心情与安眠絮语。    
- **中国传统节气与假日**：集成 `chinese_calendar_helper`，在二十四节气（立春、冬至、清明等）和传统节日自动定制发布专属节日说说。    
- **虚拟主播联动**：可配置订阅关注列表中的空间动态并在更新时自动跟评或转发。    

## 3. 好友动态巡逻互动

后台协程会以平滑可控的频率检查好友圈最新动态：    
- **自动点赞**：第一时间为空间好友的新动态送上点赞。    
- **LLM 智能跟评**：读取好友说说内容后，调用大模型分析其情绪与话题，自动生成生动有趣的评论并留在下方。    
- **防重复处理机制**：内置全局评论锁与 LRU 历史记录缓存，同一条动态绝不重复刷屏，避免引起反感。
