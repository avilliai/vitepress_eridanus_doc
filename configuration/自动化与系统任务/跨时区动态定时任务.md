# 跨时区动态定时任务

喵哈喽！这里是 Yucca~ 听到闹钟响就想缩进被窝的本猫，今天必须好好给你介绍一下 Eridanus 超级进化的定时任务系统！    
过去的机器人定时器是不是很呆？必须在 yaml 里写死几点几分，要是群友在莫斯科、加州或者东京，同一个早安问候就会变成半夜扰民……    
现在完全不一样啦！我们重构了整个框架级调度引擎，不仅支持全球城市时区自动换算，还把定时任务做成了 AI 可以自主安排的工具！    

## 1. 框架级调度架构亮点

- **全球时区智能折算**：原生联动用户注册的城市信息（`user.city`）。无论用户在莫斯科（UTC+3）、加州硅谷/卡斯特罗谷（UTC-7/UTC-8），还是东京（UTC+9），Bot 都会自动将其目标时间折算为服务器的东八区时间执行！即便是不在内置大城市字典里的小镇，系统也会通过地理编码接口自动解析并永久缓存！    
- **真正的数据库持久化**：动态定时任务完全存放在 `data/dataBase/dynamic_schedules.db` (基于 aiosqlite)。哪怕 Bot 重启、服务器断电，所有任务依然安全保留，重启后自动无缝恢复！    
- **自然语言自主安排**：只要在日常聊天中对我说“明天早上8点叫我起床”、“每天晚上11点给我发个asmr”、“两分钟后来抓我去洗澡”，AI 就会自主通过 Function Calling 创建并管理对应的任务！    
- **群聊与私聊严格隔离**：私聊创建的任务绝不会跑到群里乱叫，群聊里安排的任务也不会泄露给其他群，保护隐私滴水不漏~    

## 2. AI 对话自主管理 (Function Calling)

在 `mai_reply` 启用时，AI 拥有以下三大定时工具权限：    

### 任务创建 (`call_create_schedule_task`)

AI 可以理解多种循环周期与执行形式：    
- **一次性提醒 (`once`)**：“十分钟后提醒我关火”、“明天上午10点提醒我交报告”    
- **每天循环 (`daily`)**：“每天早上7点半叫我起床”、“每晚11点给我发个晚安”    
- **指定星期 (`weekly`)**：“每周五晚上9点提醒我打团本”    
- **工作日 / 周末 (`workday` / `weekend`)**：“工作日早上8点叫醒我，周末不要吵我”    
- **嵌套工具调用 (`function_call`)**：不仅可以发提醒文本，还能到点直接调用其他函数！例如定时执行 `call_asmr` 投喂助眠音频，或者定时调用天气预报！    
- **内置智能防抖**：当 LLM 在思考重试或连环回复时，系统会自动识别相似描述与相近触发时间，杜绝重复创建同一任务的 Bug。    

### 任务取消 (`call_cancel_schedule_task`)

如果你改变了主意，只要直接告诉我即可：    
- **自然语言取消**：“刚才那个洗澡提醒算了吧”、“取消叫我起床的任务”    
- **序号指定**：“取消第1个定时任务”、“把第二个取消掉”    
- **一网打尽**：“取消所有定时任务” / “全部取消”    

### 任务查询 (`call_list_schedule_tasks`)

记不清自己让猫猫记了哪些提醒？    
直接问：“我都有哪些定时任务？”、“查一下现在的提醒列表”。Bot 就会将当前会话下所有处于激活状态的任务、循环周期以及下次触发的精确时间排版成清单汇报给你！    

## 3. 经典群聊广播与订阅指令

除了上面的动态个性化定时任务外，Eridanus 依然完美兼容经典的整群广播订阅系统：    

### 订阅管理指令

| 指令 | 示例 | 说明 |
| :--- | :--- | :--- |
| `/cron add <任务名>` | `/cron add epic喜加一` | 为当前群聊订阅指定的广播任务 |
| `/cron add all` | `/cron add all` | 一键为当前群订阅所有支持的广播任务 |
| `/cron remove <任务名>` | `/cron remove 摸鱼人日历` | 取消当前群对指定广播任务的订阅 |
| `/cron remove all` | `/cron remove all` | 一键退订所有广播任务 |

### 当前支持的系统级广播任务名

- `早安` / `午安` / `晚安`：全群贴心问候（自动调用对话大模型生成趣味文案）    
- `epic喜加一`：Epic 每周限免游戏制图推送    
- `jm每日推送`：JM 热门绅士本子每日榜单推送    
- `nightASMR`：深夜随机治愈 ASMR 音频与封面卡片    
- `每日天文`：NASA 每日天文图文解析推送（群友亦可发送“今日天文”随时点播）    
- `单向历`：每日文艺日历卡片（群友亦可发送“单向历”随时点播）    
- `bing每日图像`：微软 Bing 每日高清壁纸与背景故事    
- `bangumi`：每日番剧放送时间表精美排版    
- `忍术大学习`：火影忍者随机忍术科普    
- `每日壁画王`：每日群内发言排行榜榜首与壁画王勋章制图    
- `摸鱼人日历`：打工人专属放假倒计时与摸鱼提醒

| :--- | :--- | :--- |
