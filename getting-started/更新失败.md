# 常见启动与更新问题排查

遇到启动报错或者更新失败别慌张！这里整理了最常见的问题成因与一步到位的解决方法。    

---

## 一键式便捷更新 (推荐)

如果你使用的是 Windows 整合包或者克隆后的完整工程，**完全不需要手动打开终端敲 `git pull`！**    
- **直接运行根目录的更新脚本**：双击运行根目录下的 `更新.bat`（或 `update.bat`），脚本会自动拉取远程最新提交并同步依赖。    
- **通知提醒联动**：在配置了 `git_update_notifier` 插件后，当远程有新 commit 时，机器人也会自动给 Master 发送更新提醒，直接运行脚本更新即可。

## 常见更新报错：Git 网络连接失败 / 连接超时

### 1. 现象
运行更新脚本或拉取代码时提示：`Failed to connect to github.com port 443: Timed out` 或 `OpenSSL SSL_read: Connection was reset`。    

### 2. 解决方案
GitHub 服务器位于海外，若网络环境受限，需要为 Git 配置代理端口。    
以 Windows 为例，在本地命令行或 MinGit 目录下输入（将端口替换为你本地代理的实际端口，如 7890 / 10809）：    
```cmd
git config --global http.proxy http://127.0.0.1:7890    
git config --global https.proxy http://127.0.0.1:7890    
```
若不再需要代理，可通过以下命令清除：    
```cmd
git config --global --unset http.proxy    
git config --global --unset https.proxy    
```

## 启动报错：ModuleNotFoundError 模块缺失

### 1. 现象
启动时提示类似：`ModuleNotFoundError: No module named 'colorlog'` 或找不到某依赖包。    

### 2. 解决方案
确认当前终端使用的是 Eridanus 对应的 Python 环境：    
```bash
# 进入项目虚拟环境或使用整合包 Python
pip install -r requirements.txt
```
对于单个偶发缺失的基础工具包，可直接补装：    
```bash
pip install colorlog
```

## OneBot 协议端未连接 / 连不上服务端

### 1. 现象
终端提示 `副Bot收到服务端响应...` 报错或无响应，QQ 无法触发消息。    

### 2. 排查步骤
1. **优先推荐 OneBot 实现**：首选推荐使用 [SnowLuma](https://snowluma.github.io/zh/)，轻量、稳定且兼容性极佳。    
2. **核对 WebSocket 端口**：    
   - Eridanus 默认内置 WebUI 与反向 WebSocket 集线器位于端口 `5007`。    
   - 请检查协议端（SnowLuma / NapCat 等）中配置的反向 WebSocket 地址是否正确指向：`ws://127.0.0.1:5007/onebot/v11/ws`。    
3. **防火墙与安全组**：如果是跨设备或云服务器部署，请确保对应的端口已在防火墙中放行。
