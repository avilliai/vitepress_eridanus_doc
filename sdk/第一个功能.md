# 第一个功能

恭喜你迈出了第一步！现在跟本猫一起，从零写一个带点趣味交互的小功能吧。    

---

## 1. 协议端前置准备

在开始写代码前，确保你的 OneBot v11 协议端已经就绪：    
- 推荐使用新一代高性能的 **[SnowLuma](https://snowluma.github.io/zh/)**（或者 NapCat / LLOneBot）。    
- 在协议端配置中开启 **正向 WebSocket**，监听地址建议设为 `ws://127.0.0.1:3001`。    
- 如果设置了 `access_token`，在实例化 bot 时填入对应的 token 参数即可。    

---

## 2. 编写你的第一个交互插件

我们来实现一个包含群聊点赞、运势问候和戳一戳互动的脚本 `my_first_bot.py`：    

```python
import asyncio
from developTools.adapters.websocket_adapter import WebSocketBot
from developTools.event.events import (
    GroupMessageEvent,
    PrivateMessageEvent,
    PokeNotifyEvent
)
from developTools.message.message_chain import MessageChain
from developTools.message.message_components import Text, At, Image, Reply

# 实例化 WebSocket 客户端
# 如果消息 ID 在某些客户端中以字符串返回，可以传入 all_str_id=True
bot = WebSocketBot("ws://127.0.0.1:3001")

# 监听群聊消息
@bot.on(GroupMessageEvent)
async def handle_fortune(event: GroupMessageEvent):
    text = event.raw_message.strip()

    if text == "/今日运势":
        # 构建消息链：艾特用户 + 回复文本
        chain = MessageChain([
            At(qq=event.sender.user_id),
            Text("
本猫掐爪一算，你今天的大吉指数是 100%！宜：摸鱼、吸猫、请赖哥喝奶茶。")
        ])
        await bot.send(event, chain)

    elif text.startswith("/点赞"):
        # 调用 OneBot 基础动作：给发送者主页点赞
        await bot.send_like(user_id=event.sender.user_id, times=10)
        await bot.send(event, MessageChain([
            Reply(id=event.message_id),
            Text("给你点了 10 个赞，手都要按酸了喵~")
        ]))

# 监听戳一戳通知
@bot.on(PokeNotifyEvent)
async def handle_poke(event: PokeNotifyEvent):
    # 如果被戳的是机器人自己
    if event.target_id == bot.id or event.target_id == event.self_id:
        await bot.send_group_message(
            group_id=event.group_id,
            message=MessageChain([
                At(qq=event.user_id),
                Text(" 别戳啦！猫毛都要被你薅秃了！喵呜！")
            ])
        )

if __name__ == "__main__":
    print("正在启动机器人，等待连接 SnowLuma...")
    bot.run()
```

## 3. 运行与验证

在终端中执行：    
```bash
python my_first_bot.py
```
当你看到终端打印出连接成功或收到心跳后，去群里发一句 `/今日运势` 或者戳戳机器人头像，看看它是不是傲娇地回复你啦！
