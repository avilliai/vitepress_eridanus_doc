# 消息组件 (MessageComponent)

消息组件是构成消息链的原子单元。所有的消息组件均继承自 `developTools.message.message_components.MessageComponent`，并严格遵守 OneBot v11 协议标准。    

---

## 1. 常见基础组件

### 文本 (`Text`)
纯文本内容：    
```python
from developTools.message.message_components import Text

t = Text(text="喵呜~今天也要元气满满哦！")
```

### 艾特 (`At`)
在群里艾特某人或全体成员：    
```python
from developTools.message.message_components import At

at_user = At(qq=1840094972)
at_all = At(qq="all")
```

### 图片 (`Image`)
发送本地图片、网络图片或 base64：    
```python
from developTools.message.message_components import Image

# 网络 URL
img1 = Image(file="https://example.com/chara.png")

# 本地文件（建议使用绝对路径或相对项目的路径）
img2 = Image(file="data/pictures/Mface/[笑].gif")

# 本地 file:// 协议
img3 = Image(file="file:///D:/images/cat.jpg")
```

### 回复引用 (`Reply`)
引用某条特定的消息（通常用于精准回答）：    
```python
from developTools.message.message_components import Reply

reply_comp = Reply(id=event.message_id)
```

### 表情 (`Face`)
QQ 自带原生大黄脸表情（根据表情 ID 发送）：    
```python
from developTools.message.message_components import Face

face = Face(id=178)  # 经典大笑表情
```

---

## 2. 多媒体与扩展组件

### 语音 (`Record`)
发送 Silk / 音频文件（支持本地音频或直连 URL）：    
```python
from developTools.message.message_components import Record

rec = Record(file="data/voice/cache/output.wav")
```

### 视频 (`Video`)
发送本地或网络视频文件：    
```python
from developTools.message.message_components import Video

video = Video(file="data/video/clip.mp4")
```

### 文件 (`File`)
发送普通文件：    
```python
from developTools.message.message_components import File

doc = File(file="data/docs/summary.pdf", name="汇报文档.pdf")
```

### 音乐分享 (`Music`)
支持网易云、QQ 音乐等卡片点播：    
```python
from developTools.message.message_components import Music

music_card = Music(type="163", id=186016)  # 网易云歌曲 ID
```

### 戳一戳 (`Poke`)
群内拍一拍：    
```python
from developTools.message.message_components import Poke

poke = Poke(type="poke", id=1840094972)
```

### 合并转发节点 (`Node`)
用于构建多条折叠的转发消息：    
```python
from developTools.message.message_components import Node, Text

nodes = [
    Node(user_id=1000000, nickname="Yucca", content=[Text("第一条测试")]),
    Node(user_id=1840094972, nickname="赖哥", content=[Text("收到收到！")])
]
await bot.send_group_forward_msg(group_id=event.group_id, messages=nodes)
```
