# 消息链 (MessageChain)

在聊天机器人中，一句话往往不仅仅是纯文字，它可能夹杂着图片、艾特某人、表情、甚至回复引用。    
为了让富文本消息的处理和构建如同原生 Python 列表一样自然，Eridanus 设计了 `MessageChain`。    

---

## 1. 什么是 MessageChain？

`MessageChain` 本质上是一个装载了多种 `MessageComponent`（消息组件）的容器类。    
它提供了像 `list` 一样的常见操作接口（`append`, `extend`, `insert`, 索引切片等），并且能够自动将组件对象转换为 OneBot v11 标准的序列化数据字典。    

```python
from developTools.message.message_chain import MessageChain
from developTools.message.message_components import Text, At, Image

# 自由组装一条图文并茂的消息
chain = MessageChain([
    At(qq=1840094972),
    Text("
赖哥！你看本猫画的这只猫咪好看嘛？
"),
    Image(file="https://example.com/cat.jpg")
])
```

---

## 2. 常用操作方法

### 提取纯文本 (`fetch_text`)
快速从混合消息链中抽取出所有的文本内容，方便做关键词过滤或命令解析：    
```python
plain_text = chain.fetch_text().strip()
```

### 检查是否包含某种组件 (`has`)
```python
from developTools.message.message_components import Image, At

if chain.has(Image):
    print("这条消息包含图片！")

if chain.has(At):
    print("有人被艾特了！")
```

### 提取指定类型的首个或全部组件 (`get`)
```python
# 获取消息中的第一张图片对象
first_img = chain.get(Image)
if first_img:
    print(f"图片地址是: {first_img.url or first_img.file}")
```

---

## 3. 动态拼接与构建

你可以像拼接积木一样追加组件：    
```python
chain = MessageChain()
chain.append(Text("早上好！"))
chain.append(Image(file="data/pictures/morning.png"))
await bot.send(event, chain)
```
