# 事件系统 (Event System)

Eridanus 的 SDK 采用完全解耦的强类型事件驱动模型。协议端推送的每一条原始 JSON 数据，都会经由 `EventFactory` 反序列化为具体的 Python 事件模型，并派发到注册了对应事件的处理器函数中。    

---

## 1. 注册事件监听器

使用 `@bot.on(EventType)` 装饰器即可订阅特定类型的事件：    

```python
from developTools.event.events import GroupMessageEvent

@bot.on(GroupMessageEvent)
async def my_handler(event: GroupMessageEvent):
    # 处理逻辑
    print(f"收到群 {event.group_id} 的消息：{event.raw_message}")
```

---

## 2. 核心事件类型分类

### 消息事件 (Message Events)
- `GroupMessageEvent`: 群聊消息事件。字段包含 `group_id`, `user_id`, `message_id`, `raw_message`, `message`（解析后的组件列表）, `sender`（包含 `nickname`, `card`, `role` 等）。    
- `PrivateMessageEvent`: 私聊好友或临时会话事件。字段包含 `user_id`, `sub_type`（friend/group/other）, `raw_message`, `message`, `sender`。    

### 通知事件 (Notice Events)
- `GroupBanNoticeEvent`: 群禁言通知（包含禁言时长 `duration`、操作者 `operator_id`、被禁言人 `user_id`）。    
- `GroupIncreaseNoticeEvent`: 群成员增加通知（新入群成员 `user_id`）。    
- `GroupDecreaseNoticeEvent`: 群成员减少通知（退群/被踢）。    
- `GroupRecallNoticeEvent`: 群消息撤回通知（包含 `message_id`、操作者 `operator_id`）。    
- `FriendRecallNoticeEvent`: 好友消息撤回通知。    
- `PokeNotifyEvent`: 戳一戳通知（包含 `group_id`, `user_id`, `target_id`）。    
- `HonorNotifyEvent`: 群荣誉变更（龙王/群聊之火等）。    

### 请求事件 (Request Events)
- `FriendRequestEvent`: 加好友请求（可用 `await bot.handle_friend_request(flag, approve)` 快速通过）。    
- `GroupRequestEvent`: 加群/邀请入群请求（可用 `await bot.set_group_add_request(flag, sub_type, approve)` 审批）。    

### 元事件 (Meta Events)
- `LifecycleMetaEvent`: 客户端生命周期变更（启动/连通）。    
- `HeartbeatMetaEvent`: 周期性心跳事件（包含 `status` 状态与心跳间隔 `interval`）。    

---

## 3. 拦截与异常隔离

每个 `@bot.on` 处理器都运行在独立的异步任务中：    
- 单个处理器的抛错不会影响其他监听器或整个 Bot 进程。    
- SDK 内置了执行耗时监控（默认超过 10 秒会输出性能警告，方便排查阻塞协程）。
