# 框架消息与事件处理

在 Eridanus 运行时环境中，`bot` 实例实际是 `ExtendBot`（继承自 `WebSocketBot`）。    
除了底层的 OneBot v11 事件订阅，它还增加了全局黑白名单阻断、权限过滤和双 Bot 联动能力。    

---

## 1. ExtendBot 增强特性

1. **自动黑白名单拦截**：    
   收到群消息或私聊时，自动对照 `data/config/common_config.yaml` 中的 `black_list_users` 和 `black_list_groups`。被拉黑的用户甚至不会进入插件处理流程，保护系统安全。    
2. **统一主从 Bot 架构 (DualBotManager)**：    
   主 Bot 负责主要业务与聊天，副 Bot 可作为群聊状态监控或备用通信通道。    
3. **离线安全模式**：    
   当 `uri` 为空时自动切换为离线模式，保证单机测试或仅运行 WebUI 服务时不抛连接异常。    

---

## 2. 事件处理的最佳实践

在编写框架插件时，请遵循以下规范：    

- **非阻塞原则**：网络请求必须使用异步库（如 `httpx.AsyncClient` 或 `aiohttp`），严禁使用阻塞式的 `time.sleep()` 或同步 `requests`。    
- **异常捕获**：在关键业务逻辑外层包裹 `try...except`，并通过 `logger.error(..., exc_info=True)` 打印堆栈，保证单个用户的异常不会影响整体运行。    
- **消息安全**：对用户输入的指令使用 `.strip()` 清理首尾空白，并在发送前确保敏感信息（如 API Key）被脱敏。
