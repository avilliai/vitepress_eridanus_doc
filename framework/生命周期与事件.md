# 生命周期与元事件流

在 Eridanus 插件开发中，除了群聊消息和私聊消息外，系统的生命周期状态（启动、停止、热重载）也是编写高稳定性服务不可或缺的一环。    

---

## 核心生命周期流

Eridanus 的主循环通过 `LifecycleMetaEvent` 向所有注册的插件广播运行阶段元事件：    

```
[启动初始化] -> [插件装载 main()] -> [LifecycleMetaEvent: enable] -> [常驻轮询/消息响应] -> [热重载/进程退出]
```

---

## 1. 监听生命周期元事件

通过 `@bot.on(LifecycleMetaEvent)` 可以捕获系统启动和状态变动通知，适合用于初始化后台常驻协程（如定时轮询、心跳广播、数据库预热）：    

```python
from developTools.event.events import LifecycleMetaEvent
import asyncio

def main(bot, config):
    @bot.on(LifecycleMetaEvent)
    async def on_lifecycle(event: LifecycleMetaEvent):
        sub_type = getattr(event, "sub_type", "")
        if sub_type == "connect" or sub_type == "enable":
            print("[插件] 机器人生命周期已就绪，启动后台监听任务...")
            asyncio.create_task(my_background_worker())

    async def my_background_worker():
        while True:
            # 执行周期性监控或数据同步
            await asyncio.sleep(60)
```

---

## 2. 插件热重载机制 (Plugin Hot-Reload)

- **动态加载**：框架的 `PluginManager` 监控 `run/` 目录变动，能够在不中断主进程连接的情况下热重载单个功能插件。    
- **状态清理**：编写带后台轮询的任务时，务必妥善管理后台协程句柄，避免热重载后产生僵尸协程或重复轮询。    

---

## 3. 双 Bot 协同架构 (DualBotManager)

Eridanus 采用双 Bot 协同架构：    
- **主 Bot**：处理常规消息接收与各业务插件的响应分发。    
- **副 Bot / WebUI 客户端**：提供实时状态同步与 WebUI 双向通信流。    
- **权限与拦截层**：任何事件分发前均会经过全局黑白名单与权限过滤器，确保恶意请求在到达插件层前被安全拦截。
